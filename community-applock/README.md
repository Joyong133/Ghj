# 🔒 커뮤니티 앱 잠금

누가 만든 앱이든, 이름이 무엇이든 **커뮤니티 앱이면 잠그는** 작은 앱입니다. 휴대폰과 메타 퀘스트에서 같은 APK로 동작하고,
[Digital Detox](../community-detox/)와 따로 설치해서 함께 쓸 수 있습니다 (패키지 `com.joyong.applock`).

## 찾는 방법
| 방법 | 동작 | 조건 |
| --- | --- | --- |
| 이름으로 찾기 | 앱 이름·패키지에 커뮤니티 이름·별명(디시, 펨코, 에타, reddit …)이 들어 있으면 잠금. 앱을 켤 때와 새 앱이 설치될 때 확인 | 항상 |
| 접속으로 찾기 | 커뮤니티 주소를 물으면 VPN 안쪽의 가짜 주소를 알려 주고, 그 주소로 접속하는 연결의 주인 앱을 안드로이드에게 물어 잠금. 연결은 바로 끊음 | 선택 (VPN). 안드로이드는 VPN을 하나만 켤 수 있어 Digital Detox의 네트워크 차단과 동시에 쓸 수 없음 |

- 잠긴 앱은 열리자마자 홈으로 보내고 "🔒 잠겨 있어요" 화면을 띄웁니다 (퀘스트 옆 패널 포함).
- 브라우저·메신저·시스템 앱·Digital Detox는 잠그지 않습니다. 짧은 영어 단어는 낱말 단위로만 비교합니다 (client, inventory 등은 안 걸림).
- 앱의 잠긴 앱 목록에서 **풀기**를 누르면 풀리고, 다시 자동으로 잠그지 않습니다.

## 설치
1. Releases의 `커뮤니티 앱 잠금 APK (최신 빌드)`에서 `AppLock.apk`를 받아 설치 (퀘스트는 SideQuest 등).
2. 앱을 열고 **접근성 설정 열기** → '커뮤니티 앱 잠금' 켜기. 회색이면 **앱 정보 (제한된 설정 허용)** → ⋮ → 제한된 설정 허용.
   (퀘스트에서는 숨어 있는 안드로이드 설정 앱을 직접 엽니다)

커뮤니티 목록·이름 비교·DNS 패킷 처리 코드는 Digital Detox와 같은 코드를 씁니다.

## 디톡스 시간 · 삭제 방지

- **디톡스 시간**: 1시간~30일 버튼이나 직접 입력(일·시간·분)으로 시작해요. 끝날 때까지 잠긴 앱을 풀 수 없고,
  '접속으로 찾기'도 끌 수 없어요. 시간은 늘릴 수만 있어요.
- **삭제 방지**: 기기 관리자 권한(다른 정책 없음)으로 앱을 바로 지울 수 없게 해요. 디톡스 시간에는 이 앱의
  삭제 창·앱 정보(강제 중지)·접근성 끄기·삭제 방지 끄기·VPN 끊기 화면을 닫아요. 다른 앱 설정은 그대로 쓸 수 있어요.
