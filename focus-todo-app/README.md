# 집중 투두 (Focus Todo) – 안드로이드 앱

할 일 목록 + **강제 집중 모드**. 정해 둔 시간이 되면 이 앱(과 전화·문자 등 허용한 앱)만 쓸 수 있습니다.

## 설치
1. `release/FocusTodo-v1.0.apk` 를 휴대폰으로 받아 설치합니다. ("출처를 알 수 없는 앱 설치" 허용 필요)
2. 앱을 열고 **접근성 설정 열기** → 설치된 앱 → **집중 투두** 켜기
   - Android 13 이상에서 "제한된 설정" 때문에 켤 수 없으면: 설정 → 애플리케이션 → 집중 투두 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 시도
3. **⏰ 집중 시간표**에서 요일·시간 등록 (예: 평일 09:00~12:00). 자정 넘김(22:00~02:00)도 가능.

## 기능
- 할 일 추가 / 완료 체크 / 삭제, 진행률 표시
- 집중 시간표: 요일 반복, 여러 개 등록, 켜기·끄기
- **지금 바로 집중**: 15분~3시간 즉시 시작 (시작하면 중간에 멈출 수 없음, 연장만 가능)
- 집중 중 강제 사항
  - 다른 앱·홈 화면·설정을 열면 즉시 집중 투두로 되돌아옴
  - 뒤로 가기로 나갈 수 없음
  - 시간표·허용 앱 변경 잠금
- 항상 허용: 전화(통화 화면 포함), 문자, 연락처, 키보드, 알림창, 긴급전화
- **✅ 허용 앱**: 카카오톡 등 추가로 허용할 앱 선택. 집중 중에는 메인 화면 상단 바로가기 버튼으로 실행

## 알아둘 점
- 차단은 접근성 서비스로 동작합니다. 접근성이 꺼져 있으면 차단되지 않습니다.
- 비상시 해제: 휴대폰을 **안전 모드**로 재부팅하면 외부 앱이 동작하지 않습니다.
- 일부 제조사(샤오미 등)는 "백그라운드에서 팝업 창 표시" 권한을 허용해야 되돌리기가 잘 됩니다.

## 빌드
```
./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
```
JDK 17+ 와 Android SDK(platform 35) 필요. `app/sideload.keystore` 는 개인 설치용 서명 키입니다(업데이트 설치 시 같은 서명 유지용, 비밀번호 `android`).
