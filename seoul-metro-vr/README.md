# 서울 지하철 1·2호선 VR 체험

Godot 4.3 + Blender로 만든 VR 지하철 탑승 체험이에요. Meta Quest 같은 OpenXR 헤드셋에서 실행하고,
1호선(102개 역)과 2호선(51개 역)의 **모든 역**을 실제 운행 시간에 맞춰 타고 다닐 수 있어요.

## 주요 기능

- **전체 역 운행**
  - 2호선: 순환선 43개 역 (외선/내선), 성수지선, 신정지선
  - 1호선: 연천 ↔ 신창(경부선), 연천 ↔ 인천(경인선), 영등포 ↔ 광명 셔틀, 구로 ↔ 서동탄
  - 메뉴에서 노선, 방향, 출발역을 골라 어느 역에서든 바로 탈 수 있어요.
- **실제와 같은 시간 흐름**: 1배속이 현실 시간이에요. 역 사이 거리, 전동차 가속도(약 3.0km/h/s)와
  감속도(약 3.5km/h/s), 최고 운행 속도, 정차 시간(30초, 환승역은 더 길게)으로 구간 시간을 계산해요.
  - 예: 2호선 순환선 한 바퀴는 정차 시간을 포함해 약 1시간 28분이에요.
  - 메뉴에 현재 시각, 다음 역 도착 예정 시각, 남은 거리, 속도를 보여 줘요.
  - 필요하면 2·5·10·30·60배속으로 빠르게 가거나, 다음 역 도착 직전으로 건너뛸 수 있어요.
- **실제 서울 지하철 디자인을 참고한 열차**
  - 10량 편성, 객차 길이 19.5m, 한쪽 4개 출입문, 노선색(1호선 파랑 / 2호선 초록) 띠
  - 객차 안: 7인 일반석, 노약자석, 임산부 배려석(분홍), 손잡이와 선반, 문 위 LCD 안내기, 양 끝 노선도
  - 선두차에 행선 표시기, 전조등과 후미등
- **역**
  - 지하역, 지상역, 고가역 3가지 형태와 섬식/상대식 승강장
  - 스크린도어(문 번호 `4-2` 같은 승강장 번호 포함), 역명판(역번호, 이전역/다음역, 환승 노선), LED 전광판, 출구 안내판, 계단, 벤치
  - 1호선 지상 구간은 노란 안전선과 점자블록, 승강장 지붕, 선상역사
- **역 사이 풍경**: 지하 터널(조명과 케이블), 지상 선로(자갈, 침목, 전차선), 고가 구간, 한강 철교
  (한강철교, 잠실철교, 당산철교), 도시 건물, 터널 입구
- **안내방송**: 차임 소리와 자막으로 안내해요.
  - 예: "이번 역은 강남, 강남역입니다. 내리실 문은 왼쪽입니다", 환승 안내, 종착역 안내
  - 출입문 경고음, 주행음, 인버터 소리, 레일 이음매 소리(1호선 지상 구간)도 나와요.
- **내리기**: 문이 열려 있을 때 승강장으로 걸어 나가 역을 둘러볼 수 있어요. 밖에 있으면 열차가 출발하지 않고 기다려요.
- 종착역에 도착하면 잠시 쉰 뒤 반대 방향으로 회차해요.

## 설치 (Meta Quest 2 / 3 / 3S / Pro)

미리 빌드한 APK 파일은 `release/SeoulMetroVR.apk`에 있어요.

1. Quest를 [개발자 모드](https://developer.oculus.com/documentation/native/android/mobile-device-setup/)로 바꿔요.
2. PC와 USB로 연결한 뒤 설치해요. SideQuest를 쓰거나 아래 명령을 실행하면 돼요.
   ```
   adb install -r SeoulMetroVR.apk
   ```
3. Quest의 앱 목록에서 **알 수 없는 출처**를 열고 **서울지하철VR**을 실행해요.

## 조작법

| 동작 | VR 컨트롤러 | PC (헤드셋 없을 때) |
|---|---|---|
| 걷기 | 왼쪽 스틱 | W A S D |
| 회전 | 오른쪽 스틱 좌우 (30°씩) | 마우스 |
| 메뉴 열기/닫기 | Y 또는 B 버튼 | Tab |
| 메뉴 누르기 | 레이저로 가리키고 트리거 | 화면 가운데 점 + 클릭 |

앉아서 플레이할 때는 메뉴의 `설정`에서 **앉아서 플레이(시점 +45cm)** 를 켜세요.
`운행 정보` 화면의 **좌석에 앉기** 버튼을 누르면 객차 좌석으로 이동해요.

## 빌드 방법

### 1. Blender 모델 다시 만들기 (선택)
`assets/models/*.glb` 파일은 이미 들어 있어요. 모델을 고쳤다면 아래 명령으로 다시 만들어요.
```
blender -b --factory-startup -P blender/build_models.py -- assets/models
```
이 명령은 `train_car.glb`(객차), `train_cab.glb`(선두부), `station_props.glb`(스크린도어, 벤치, 지붕, 계단)를 만들어요.

### 2. APK 만들기
```
tools/build_apk.sh        # 결과물: build/SeoulMetroVR.apk
```
필요한 것:
- Godot 4.3과 Android 내보내기 템플릿
- JDK 17 이상
- `apksigner`, `zipalign` (Android SDK build-tools)

`apktool`과 Khronos OpenXR 로더는 스크립트가 자동으로 내려받아요.

Godot 4.3에서 OpenXR APK를 만들려면 원래 Gradle 빌드(Android SDK 전체)가 필요해요.
이 스크립트는 Gradle 없이 기본 템플릿으로 내보낸 뒤, Gradle 빌드가 하는 일을 직접 적용해요(`tools/patch_openxr.py`).
- OpenXR 로더 넣기
- VR 매니페스트 항목 추가: `com.oculus.intent.category.VR`, OpenXR 권한, 런타임 브로커 query
- 실행 플래그 `--xr_mode_openxr` 설정

Android SDK가 있다면 Godot 에디터에서 `xr_features/xr_mode = OpenXR`과 `Use Gradle Build`를 켜고 내보내도 돼요.

### 3. PC에서 실행
Godot 4.3으로 이 폴더를 열고 실행하면 돼요. 헤드셋이 없으면 PC 모드로 실행돼요.

## 프로젝트 구조

```
blender/build_models.py   Blender 모델 생성 스크립트 (객차/선두부/역 소품)
assets/models/            Blender 결과물 (.glb)
assets/fonts/             나눔바른고딕 (OFL)
scripts/metro_data.gd     1·2호선 역 데이터 (역명, 영문명, 역번호, 구조, 환승, 역간 거리)
scripts/main.gd           운행 시뮬레이션 (정차, 출입문, 가감속, 안내방송, 표시기)
scripts/train.gd          열차 배치, 출입문, LCD, 노선도, 행선표시기
scripts/station_builder.gd 역 생성 (지하/지상/고가, 섬식/상대식)
scripts/scenery.gd        역 사이 풍경 (터널/지상/고가/철교/건물)
scripts/player.gd         VR 플레이어 (OpenXR) + PC 모드
scripts/menu_ui.gd, panel3d.gd  VR 메뉴
scripts/audio_synth.gd    효과음 합성
tools/build_apk.sh        APK 빌드
```

## 참고와 한계

- **역간 거리**: 공개된 노선 자료를 바탕으로 정리한 근사값이에요(2호선 순환선 합계는 실제 48.8km에 맞췄어요).
  그래서 구간 시간은 실제 시간표와 몇십 초 정도 다를 수 있어요.
- **역 디자인**: 서울 지하철 역의 공통 양식(역명판, 스크린도어, 전광판 등)을 재현했어요.
  역마다 다른 실제 구조(출구 위치, 기둥 배치, 승강장 형식)까지 똑같이 만들지는 않았어요.
  - 섬식/상대식은 역마다 정확한 자료가 없어서 정해진 규칙으로 골랐어요.
  - 내리는 문 방향은 좌측통행 기준으로 이 승강장 형식에 맞춰요.
- **안내방송**: 음성 대신 차임과 자막(한국어·영어)으로 안내해요.
- **역번호**: 1호선 연천 연장 구간(청산, 전곡, 연천)과 탕정역은 역번호를 표시하지 않아요.
- **실기기 테스트**: APK는 Quest용 OpenXR 설정으로 빌드했지만, 실제 헤드셋에서는 아직 시험하지 못했어요.
