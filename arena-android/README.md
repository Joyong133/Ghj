# Arena 안드로이드 앱 (APK)

[arena.ai](https://arena.ai)를 브라우저 없이 앱 화면 전체로 여는 안드로이드 앱입니다.
홈 화면의 **Arena** 아이콘을 누르면 주소창 없이 바로 arena.ai가 열립니다.

## 설치하기

휴대폰에서 아래 링크를 열면 항상 최신 APK를 받습니다.

**https://github.com/Joyong133/Ghj/releases/download/arena-android-latest/Arena.apk**

1. 받은 `Arena.apk`를 엽니다.
2. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켭니다.
3. **설치**를 누릅니다.

새 버전도 같은 링크로 받아 설치하면 로그인 상태를 그대로 둔 채 업데이트됩니다.

## 기능

- **답변 분량 정하기**: 노란 프롬프트 버튼 목록 맨 위에서 분량(숫자 + 글자/문장/문단 + 이내/정도)을
  정하고 켜 두면, 보낼 때 질문 끝에 `[분량: 공백 포함 500자 이내로 답해 줘]` 같은 지시를 자동으로 붙입니다.
  보내기 버튼과 엔터 모두 적용되고, 이미 붙어 있으면 다시 붙이지 않습니다. 스위치로 바로 끌 수 있습니다.
  AI는 글자 수를 정확히 세지 못해 대략 맞추고, 문장·문단 수가 더 잘 지켜집니다.
- **고정 모드 (📌)**: 배틀 모드는 질문할 때마다 모델이 무작위로 바뀝니다. 투표해서 모델 이름이
  공개된 뒤 📌 버튼을 누르고 고정할 AI를 고르면, 다이렉트 모드로 옮겨 그 모델을 자동으로 고르고
  계속 대화할 수 있습니다.
  - **이어가기**를 고르면 지금까지의 질문과 그 AI의 답변을 입력창에 넣어 줍니다. 끝에 이어서 물어볼 말을 적고 보내면 됩니다.
  - 고정 중에는 📌 버튼이 초록색이고, 새 대화를 열어도 고정한 모델로 다시 맞춰 줍니다.
  - 다이렉트 모드에서 누르면 지금 쓰는 모델로 고정합니다. 고정 중에 누르면 해제하거나 다른 AI로 바꿀 수 있습니다.
  - 모델 이름을 찾지 못하면 모델 목록을 열어 주고, 거기서 고른 모델로 고정합니다.
- **스르륵 모드**: 답변이 다 나온 뒤 화면 오른쪽의 남색 ▶ 버튼을 누르면, 그 답변을 처음부터
  원하는 속도로 한 글자씩 다시 보여 줍니다. 제목·굵은 글씨·목록·코드·표 같은 서식은 그대로입니다.
  - 아래 막대에서 속도(초당 5~150자), 재생/일시정지, 다른 답변 고르기, 닫기를 할 수 있습니다.
    끝까지 본 뒤 ▶를 누르면 처음부터 다시 보여 줍니다.
  - 글 위를 톡 누르면 재생/일시정지, 손으로 스크롤하면 잠깐 자동 따라가기를 멈춥니다.
  - **비 내리기**를 체크하면 글 뒤로 비가 내립니다. 옆의 **하·중·상**으로 비 강도를 고르면 빗줄기 양·속도·바람·물안개와 빗소리(빗소리·창문·지붕)가 함께 세집니다. 원근감 있는 빗줄기, 바람, 바닥에 튀는 물방울,
    유리창에 맺혀 흘러내리는 물방울, 아래쪽 물안개까지 그립니다.
  - 대결 모드처럼 답변이 두 개면 하나를 고르거나 차례로 볼 수 있습니다.
  - 답변을 자동으로 못 찾으면 화면에서 볼 답변을 직접 누르면 됩니다.
  - 정한 속도는 기억합니다. 뒤로 가기를 누르면 닫힙니다.
  - **끝까지 보기 잠금**(처음엔 켜짐): 스르륵을 켜면 다 볼 때까지 닫기(🔒)·뒤로 가기·다른 답변 고르기가 막힙니다.
    일시정지와 속도 조절은 됩니다. 앱을 껐다 켜거나 페이지가 새로 열려도 그 대화가 열리면 스르륵이 자동으로 다시 켜져
    보던 곳부터 이어집니다. 끝까지 보면 풀리고, 보기 설정에서 끌 수 있습니다(다 보기 전에는 바꿀 수 없음).
  - 끝까지 보기 잠금 중에는 **글자 속도가 고정**됩니다(🔒 표시). 시작할 때의 속도로 끝까지 가고, 다 보면 다시 바꿀 수 있습니다.
  - **🎯 원앱 집중** (OneFocus 기능): 끝까지 보기 잠금으로 스르륵을 열면 바로 원앱 집중 창이 뜹니다.
    **⏱ 타이머**를 누르면 스르륵에 나온 남은 시간만큼 맞춰지고, **집중 시작**을 누르면 다 읽을 때까지 「Arena」만 쓸 수 있습니다
    (홈·최근 앱·다른 앱 실행이 막히고, 나가면 바로 다시 열림). **스르륵을 멈추면 집중 타이머도 같이 멈춥니다.**
    알림에 "「Arena」 집중 중 · 남은 시간"이 보이고, 끝까지 읽으면 "🎉 집중 완료!"와 함께 풀립니다.
    전화·메시지·연락처·카카오톡과 **＋ 허용할 앱 추가**로 고른 앱은 집중 중에도 쓸 수 있습니다.
    잠금은 접근성 기능('Arena 원앱 집중 잠금')으로 하며, 창 안에서 켜는 방법을 안내합니다
    ('제한된 설정'이 뜨면 앱 정보 → ⋮ → 제한된 설정 허용). '스르륵만 보기'를 고르면 집중 없이 봅니다.
    보기 설정의 '스르륵 열 때 원앱 집중 띄우기'로 끌 수 있습니다.
    집중 중에 Arena 화면에서는 아래쪽 버튼 줄(뒤로·홈·최근 앱)이 숨겨집니다. 아래 끝을 쓸어 올리면 잠깐 나오지만, 눌러도 바로 Arena로 돌아옵니다.
  - **집중 소리**: 막대의 🔊에서 빗소리·창문 빗소리·지붕 빗소리·파도·모닥불·시냇물·숲·백색소음·분홍소음·갈색소음·집중 비트(이어폰) 중 고릅니다.
    모두 음원 파일 없이 앱이 만든 소리이고, 비 내리기와 따로 고를 수 있습니다.
  - **Aa 버튼(보기 설정)**: 화면 색 8가지(기본·밤·종이·숲·바다·노을·민트·고대비), 글자 크기(80~200%),
    줄 간격, 글꼴(기본·고딕·명조), 읽는 줄 강조(지금 문단만 또렷하게), 깜빡이는 커서, 빗소리 크기.
    바꾸는 즉시 적용되고 기억합니다. 막대에는 지금 속도로 끝까지 남은 시간이 나옵니다.
  - **어디까지 봤는지 저장합니다.** 스르륵을 닫거나 앱을 나가도(앱이 꺼져도) 같은 답변에서 다시
    ▶를 누르면 멈춘 곳부터 이어서 보여 줍니다. 끝까지 보면 기록이 지워집니다.
- **저장한 프롬프트**: 화면 오른쪽의 노란 버튼을 누르면 자주 쓰는 프롬프트 목록이 나오고,
  하나를 누르면 arena.ai 입력창에 바로 들어갑니다. 입력창에 이미 글이 있으면 줄을 바꿔 이어 붙입니다.
  - **새 프롬프트**로 직접 적어 저장하거나, **입력창 내용 저장**으로 지금 입력창에 쓴 글을 그대로 저장합니다.
  - ⋮ 버튼(또는 길게 누르기)으로 수정·복사·맨 위로·삭제를 할 수 있고, 6개 이상이면 검색창이 나옵니다.
  - 버튼은 위아래로 끌어서 옮길 수 있고, 옮긴 위치를 기억합니다.
  - 처음에는 예시 프롬프트 4개가 들어 있습니다. 필요 없으면 지우면 됩니다.
  - 프롬프트는 휴대폰 안에만 저장되고, 앱을 지우면 함께 지워집니다.
- 로그인 상태(쿠키)를 기억합니다.
- 구글 등 로그인 팝업은 앱 안에서 열리고, arena.ai와 상관없는 링크는 기본 브라우저로 열립니다.
- 이미지 첨부(파일 선택)가 됩니다.
- 뒤로 가기 버튼은 이전 페이지로 이동하고, 첫 페이지에서는 앱을 닫습니다.
- 인터넷이 끊기면 안내 화면이 나오고, 연결되면 자동으로 다시 엽니다.
- 다른 앱에서 arena.ai 링크를 누를 때 이 앱으로 열 수 있습니다.
- 휴대폰의 다크 모드를 따릅니다.

## 알아 둘 점

- 구글은 앱 내장 브라우저에서의 로그인을 막는 경우가 있습니다. 이 앱은 일반 Chrome처럼
  보이도록 설정했지만, 그래도 막히면 다른 로그인 방법을 쓰세요.
- 업데이트하려면 매번 같은 서명 키로 서명돼야 합니다. 서명 키는 저장소에 올리지 않고
  GitHub Actions 캐시에 보관합니다. 캐시는 7일 동안 빌드가 없으면 지워질 수 있고, 그러면 새 키로
  서명돼서 기존 앱을 지우고 다시 설치해야 합니다. 키를 영구히 고정하려면 아래 **서명 키 고정하기**를 따르세요.
- arena.ai는 외부 서비스이고, 이 앱은 그 웹사이트를 띄워 주기만 하는 비공식 앱입니다.

## 서명 키 고정하기 (선택)

PC에서 한 번만 하면 됩니다. JDK의 `keytool`이 필요합니다.

```bash
keytool -genkeypair -keystore arena.keystore -storetype PKCS12 -alias arena \
  -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Arena" \
  -storepass 원하는비밀번호 -keypass 원하는비밀번호
base64 -w0 arena.keystore    # 출력된 긴 문자열을 복사
```

저장소의 **Settings → Secrets and variables → Actions**에서 Secret 두 개를 추가합니다.

- `ARENA_KEYSTORE_BASE64`: 위에서 복사한 문자열
- `ARENA_KEYSTORE_PASSWORD`: 정한 비밀번호

Secret을 추가하면 키가 바뀌므로, 이미 설치한 앱은 한 번 지우고 다시 설치해야 합니다.
그 뒤로는 계속 덮어 설치됩니다. `arena.keystore` 파일은 저장소에 올리지 마세요.

## 직접 빌드하기

JDK 17과 Android SDK가 필요합니다.

```bash
cd arena-android
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

GitHub에 푸시하면 Actions의 **Arena APK 빌드**가 자동으로 APK를 만들어 위 링크에 올립니다.
