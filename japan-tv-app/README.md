# 일본TV — 일본 방송 틀어 두고 일본어 귀 트이기

일본 방송사가 유튜브에 **무료로 공개하는 공식 24시간 라이브**를 TV처럼 바로 틀어 주는 안드로이드 앱입니다.
일본어 공부용으로 계속 틀어 둘 수 있게 만들었습니다.

## 받기

GitHub 저장소의 **Releases → `일본TV 앱 (최신 빌드)`** 에서 `japan-tv.apk` 를 휴대폰으로 받아 설치하세요.
(처음 설치할 때 '출처를 알 수 없는 앱 설치'를 허용해야 할 수 있습니다. 새 빌드를 받아 설치하면 기존 앱 위에 업데이트됩니다.)

드라마 채널은 공식 채널 영상을 TV처럼 차례로 이어서 틀어 줍니다. 방송국 유튜브는 전편보다 명장면·요약 영상이 많습니다.
(전편 무료는 주로 TVer에서 하는데, TVer는 한국에서 볼 수 없습니다. ABEMA의 24시간 드라마 채널도 일본 안에서만 볼 수 있습니다.)
채널을 추가할 때 분류를 `드라마`로 고르면, 그 채널(유튜브 채널 `/videos` 주소나 검색 주소)의 영상도 `드라마 24시간 (모아 틀기)`에 함께 섞입니다.

채널 주소의 `/live` 는 그 채널에서 지금 방송 중인 라이브로 바로 연결됩니다. 방송이 없을 때는 채널 화면이 열립니다.

## 기능

- **영상만 화면 가득**: 채널을 누르면 그 채널에서 지금 방송 중인 라이브를 찾아서, 유튜브 공식 임베드 플레이어로
  영상만 검은 화면에 꽉 차게 틀어 줍니다. (유튜브 페이지, 댓글, 추천 영상 없음)
  - 임베드가 막힌 방송은 유튜브 페이지를 열고 영상 부분만 화면 가득 보이게 합니다.
- **TV처럼 조작**: 화면을 한 번 누르면 메뉴, 좌우로 밀거나 ◀ ▶ 버튼으로 채널 변경(같은 분류 안에서), 화면 꺼짐 방지
- **분류**: 첫 화면에서 전체 / 뉴스·날씨 / 드라마 / 내 채널
- **드라마·동영상**: 다음 영상 자동 재생, ⏪ 10초 / ⏯ / ⏩ 10초, 영상 제목 표시
- **가로 화면 고정** (메뉴의 회전 버튼으로 해제)
- **일본어 + 한국어 자막**: 메뉴의 자막 버튼을 누를 때마다 `일본어+한국어 → 한국어 → 일본어 → 끔`
  - 유튜브 플레이어가 보여 주는 일본어 자막(자동 생성 포함)을 읽어서 구글 번역으로 한국어로 옮기고, 화면 아래에 두 줄로 보여 줍니다.
  - 유튜브 자막이 있는 영상에서만 나옵니다. 뉴스 생방송은 자막이 없는 경우가 많고, 드라마·동영상은 대부분 자동 생성 자막이 있습니다.
  - 자막 버튼에 상태가 함께 나옵니다: `확인 중` / `자막 없음` / `유튜브 자막`
  - 앱이 플레이어 안의 자막 글자를 읽지 못하는 휴대폰에서는 유튜브 자막을 그대로 켜고, 한국어는 유튜브 자동 번역으로 보여 줍니다.
  - 번역 요청이 너무 많으면 구글이 잠시 막을 수 있어서, 그때는 1분 쉬었다가 다시 번역합니다.
- **다른 라이브**: 검색형 채널(FNN, 지금 방송 중인 일본 뉴스)은 다른 라이브로 바꿔 볼 수 있음
- **앱 켜면 마지막 채널 바로 재생** (메뉴에서 끌 수 있음)
- **작은 화면(PIP)**: 보는 중에 홈 버튼을 누르면 다른 앱을 쓰면서 계속 보기
- **자동 재연결**: 방송이 끝나거나 끊기면 다시 찾아서 연결
- **공부 기록**: 오늘 들은 시간, 하루 목표(30분~4시간), 연속 일수, 누적 시간
- **채널 추가/수정/삭제/순서 바꾸기** (채널을 길게 누르기)
  - 유튜브 채널·영상 주소
  - `@핸들` (예: `@weathernews`) → 그 채널의 라이브로 연결
  - `m3u8` / `mpd` / `mp4` 같은 스트림 주소 → 앱 안의 플레이어(ExoPlayer)로 직접 재생

## 공부 팁

- 유튜브 플레이어의 ⚙ → 자막에서 **일본어(자동 생성) 자막**을 켜면 듣기와 읽기를 같이 연습할 수 있습니다. (자막이 없는 방송도 있습니다.)
- 처음에는 이해가 안 돼도 매일 틀어 두는 것이 중요합니다. 하루 목표 시간을 정해 두세요.

## 참고

- TVer, NHK+ 같은 일본 국내 전용 서비스는 한국에서 재생되지 않아서 넣지 않았습니다.
- 유튜브 공식 플레이어로 재생하므로 유튜브 광고가 나올 수 있습니다. 광고 건너뛰기 버튼은 메뉴의 '화면 직접 누르기'를 누른 뒤 누르면 됩니다.

## 직접 빌드

```bash
cd japan-tv-app
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

`.github/workflows/japan-tv-apk.yml` 이 `japan-tv-app/` 이 바뀔 때마다 APK를 빌드해서 `japan-tv-latest` 릴리스에 올립니다.
`app/debug.keystore` 는 업데이트 설치가 되도록 매 빌드를 같은 키로 서명하기 위한 개인용 키입니다.
