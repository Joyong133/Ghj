# 일본TV — 일본 방송 틀어 두고 일본어 귀 트이기

일본 방송사가 유튜브에 **무료로 공개하는 공식 24시간 라이브**를 TV처럼 바로 틀어 주는 안드로이드 앱입니다.
일본어 공부용으로 계속 틀어 둘 수 있게 만들었습니다.

## 받기

GitHub 저장소의 **Releases → `일본TV 앱 (최신 빌드)`** 에서 `japan-tv.apk` 를 휴대폰으로 받아 설치하세요.
(처음 설치할 때 '출처를 알 수 없는 앱 설치'를 허용해야 할 수 있습니다. 새 빌드를 받아 설치하면 기존 앱 위에 업데이트됩니다.)

## 기본 채널

| 채널 | 내용 |
| --- | --- |
| ☀️ ウェザーニュースLiVE | 24시간 날씨 생방송. 말이 또박또박하고 표현이 반복돼서 입문자에게 추천 |
| 📰 日テレNEWS24 | 니혼TV 24시간 뉴스 라이브 |
| 📺 TBS NEWS DIG | TBS·JNN 뉴스 라이브 |
| 🗾 ANNnewsCH | 테레비아사히(ANN) 뉴스 라이브 |
| 🎙️ FNNプライムオンライン | 후지TV(FNN) 뉴스 – 지금 방송 중인 라이브 목록 |
| 🔴 지금 방송 중인 일본 뉴스 | 유튜브에서 실시간 방송 중인 일본 뉴스 찾기 |

채널 주소의 `/live` 는 그 채널에서 지금 방송 중인 라이브로 바로 연결됩니다. 방송이 없을 때는 채널 화면이 열립니다.

## 기능

- **TV처럼 보기**: 채널을 누르면 바로 재생, 위쪽 ◀ ▶ 버튼으로 채널 넘기기, 화면 꺼짐 방지
- **앱 켜면 마지막 채널 바로 재생** (메뉴에서 끌 수 있음)
- **가로로 돌리면 영상만 화면 가득**
- **작은 화면(PIP)**: 보는 중에 홈 버튼을 누르면 다른 앱을 쓰면서 계속 보기
- **자동 재연결**: 스트림이 끊기면 3초 → 최대 30초 간격으로 다시 연결
- **공부 기록**: 오늘 들은 시간, 하루 목표(30분~4시간), 연속 일수, 누적 시간
- **채널 추가/수정/삭제/순서 바꾸기** (채널을 길게 누르기)
  - 유튜브 채널·영상 주소
  - `@핸들` (예: `@weathernews`) → 그 채널의 라이브로 연결
  - `m3u8` / `mpd` / `mp4` 같은 스트림 주소 → 앱 안의 플레이어(ExoPlayer)로 직접 재생

## 공부 팁

- 유튜브 플레이어의 ⚙ → 자막에서 **일본어(자동 생성) 자막**을 켜면 듣기와 읽기를 같이 연습할 수 있습니다. (자막이 없는 방송도 있습니다.)
- 처음에는 이해가 안 돼도 매일 틀어 두는 것이 중요합니다. 하루 목표 시간을 정해 두세요.

## 참고

- TVer, NHK+ 같은 일본 국내 전용 서비스는 한국에서 재생되지 않아서 넣지 않았습니다.
- 유튜브 화면은 앱 안의 웹 화면으로 보여 주므로 유튜브 광고가 나올 수 있습니다.

## 직접 빌드

```bash
cd japan-tv-app
./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

`.github/workflows/japan-tv-apk.yml` 이 `japan-tv-app/` 이 바뀔 때마다 APK를 빌드해서 `japan-tv-latest` 릴리스에 올립니다.
`app/debug.keystore` 는 업데이트 설치가 되도록 매 빌드를 같은 키로 서명하기 위한 개인용 키입니다.
