# 🌿 Digital Detox (Android)

(예전 이름: 커뮤니티 디톡스)

커뮤니티 앱과 사이트를 막아 주는 안드로이드 앱입니다.
습관처럼 커뮤니티를 열면 화면을 닫고 "잠깐, 디톡스 중이에요" 안내와 함께 다른 할 일을 제안합니다.

## 무엇을 막나요?

총 55곳(기본으로 50곳 켜짐). 목록이 늘어나면 기존 사용자도 새 커뮤니티가 자동으로 켜지고, 직접 꺼 둔 곳은 그대로 유지됩니다.

- 차단 목록은 메인 화면의 **📋 차단 목록 → 차단 목록 보기 · 편집** 메뉴에 따로 있습니다. 이름이나 주소로 **검색**할 수 있습니다.
- 항목마다 켜고 끌 수 있고, **목록에 없는 사이트 주소**나 **설치된 앱**도 직접 추가할 수 있습니다.
- 사이트는 하위 주소까지 막습니다. (`dcinside.com` → `gall.dcinside.com`, `m.dcinside.com` 모두 차단)

## 기능

- **앱 차단**: 차단한 앱이 열리면 홈 화면으로 보내고 안내 화면을 띄웁니다.
- **사이트 차단**: 크롬, 삼성 인터넷, 웨일, 엣지, 파이어폭스, 오페라, 브레이브, 덕덕고 등 브라우저의 주소창을 확인해 차단한 사이트면 뒤로 돌아갑니다.
- **네트워크 차단 (VPN 방식)**: 기기 전체에서 커뮤니티 주소를 찾지 못하게(DNS) 막습니다. 모든 브라우저, 카카오톡 인앱 브라우저, 다른 앱 속 링크까지 적용됩니다.
  주소 확인(DNS)만 이 기능을 거치고 다른 통신은 그대로이며, 아무것도 기록하지 않습니다. 다른 VPN 앱과 함께 쓸 수 없습니다. 집중 디톡스 중에는 끌 수 없습니다.
- **커뮤니티 앱 설치 막기**: 플레이스토어·갤럭시 스토어·원스토어에서 차단 목록에 있는 커뮤니티 앱의 설치 화면이 열리면 바로 닫습니다. APK 파일 등 다른 방법으로 설치되면 곧바로 삭제 화면을 띄웁니다 (그 앱은 원래도 열리지 않음). 기본으로 켜져 있고, 집중 디톡스 중에는 끌 수 없습니다.
- **앱 속 화면 막기 — 토스증권**: 📋 차단 목록에서 켜면 토스 앱은 그대로 쓰되 **증권 탭·토스증권 화면·주식 사고팔기 화면**이 열리면 뒤로 돌아갑니다. 송금·결제·혜택은 막지 않습니다. 웹(tossinvest.com)도 함께 막습니다. (집중 디톡스 중에는 끌 수 없음)
- **📖 모아읽기**: 펨코 해외축구·롤 인기글, 디시 특갤 개념글, 아카 나무 실검을 브라우저 대신 이 앱 안에서만 댓글까지 읽습니다 (메인 화면의 📖 모아읽기 카드). 자세한 내용은 아래 VR 버전의 모아읽기 설명과 같습니다.
- **설정에서 이 앱의 VPN 끄기 막기** (VPN 카드의 스위치, 기본 켜짐): 시스템 설정의 이 앱 VPN 화면(연결 해제·VPN 삭제)이나 VPN 알림의 "연결 해제" 창이 열리면 바로 닫습니다. VPN 목록, 다른 앱의 VPN, VPN 연결 허용 창은 그대로입니다. 집중 디톡스 중에도 자유롭게 켜고 끌 수 있고, 접근성 권한이 필요합니다.
- **카카오톡 인앱 브라우저 차단**: 카카오톡(라인, 텔레그램, 밴드 등 포함)에서 링크를 눌러 앱 안에서 열린 페이지도
  화면 위쪽의 주소·제목을 보고 차단 목록의 커뮤니티면 닫고 대화방으로 돌아갑니다.
  **"카카오톡 인앱 브라우저 아예 막기"** 를 켜면 카톡 안에서 열리는 링크를 모두 닫습니다. (집중 디톡스 중에는 끌 수 없음)
- **집중 디톡스 (잠금)**: 정한 시간 동안 차단을 끄거나 목록에서 뺄 수 없게 잠급니다. (추가는 언제든 가능)
  - 빠른 버튼(30분 ~ 7일) 또는 **일·시간·분을 직접** 고르거나 **끝나는 날짜·시각**을 지정할 수 있습니다.
  - 진행 중에는 +10분 ~ +3일 버튼이나 직접 정한 시간만큼 **연장**할 수 있습니다. (줄이기는 불가)
- **일시정지 (1회)**: 집중 디톡스마다 딱 한 번, 5 · 10 · 15 · 30분 동안 차단을 풀 수 있습니다.
  일시정지 동안 디톡스 시간은 멈추고(끝나는 시각이 그만큼 늦춰짐), 일찍 다시 시작하면 남은 일시정지 시간은 돌려받습니다. 삭제 방지는 계속 켜져 있습니다.
- **삭제 방지**: 앱 안에서 켜면 기기 관리자로 등록되어 바로 지울 수 없습니다. (지우려면 먼저 앱에서 삭제 방지를 끄세요)
  - 집중 디톡스 중에는 **이 앱의** 삭제 확인창, 앱 정보(강제 중지·데이터 삭제), 접근성 상세(끄기 스위치·중지 확인창), 삭제 방지 해제 화면만 닫습니다.
  - 접근성 목록, 애플리케이션 목록, 다른 앱의 접근성·앱 정보 화면은 그대로 쓸 수 있습니다.
  - 앱 업데이트 설치는 막지 않습니다. 안전 모드 부팅이나 PC(ADB)로 지우는 것까지는 막을 수 없습니다.
- **앱 안에서 바로 업데이트**: 새 버전이 있으면 메인 화면 맨 위에 "✨ 새 버전이 있어요"가 뜨고, **지금 업데이트**를 누르면 앱이 직접 받아서 설치합니다 (브라우저·파일 관리자 필요 없음). 처음 한 번만 Android가 '이 출처 허용'과 '업데이트할까요?'를 묻고, Android 12 이상에서는 그다음부터 확인 없이 업데이트될 수 있습니다. 설정과 기록은 그대로입니다.
- **기록**: 오늘 참은 횟수, 누적 횟수, 디톡스 며칠째인지 보여 줍니다.
- 다크 모드 지원, 광고·추적·인터넷 권한 없음.

## 🥽 VR 버전 (메타 퀘스트 · 피코)

단독형 VR 헤드셋(안드로이드 기반)용 `CommunityDetox-VR.apk` 를 같이 빌드합니다. 앱 이름은 **커뮤니티 디톡스 VR** 이고, 헤드셋 안에서 2D 창으로 열립니다.
(PC VR — Steam VR, Quest Link/에어링크 — 은 [Windows 버전](../community-detox-pc/)이 PC에서 그대로 막아 줍니다.)

VR 앱은 **VPN(DNS) 방식**으로 막습니다. 휴대폰 앱과는 다른 별도 앱(`com.joyong.communitydetox.vr`)이라 서로 영향을 주지 않습니다.

1. 휴대폰으로 `CommunityDetox-VR.apk` 를 받습니다 (Releases).
2. 헤드셋의 **개발자 모드**를 켜고(휴대폰의 Meta Horizon 앱 → 기기 → 개발자 모드), 헤드셋에 설치합니다.
   - 휴대폰에서: USB-C 케이블로 휴대폰과 헤드셋을 연결하고 **Bugjaeger** 같은 ADB 앱으로 APK 설치
   - PC에서: **SideQuest** 또는 `adb install CommunityDetox-VR.apk`
3. 헤드셋 앱 목록 → **출처를 알 수 없음** 에서 **커뮤니티 디톡스 VR** 을 열고 **VPN 연결 허용** 을 누르면 끝입니다.
   퀘스트 브라우저를 포함한 모든 앱에서 커뮤니티 주소가 열리지 않고, 헤드셋을 다시 켜도 자동으로 다시 켜집니다.
4. 허용 창이 뜨지 않으면 한 번만 실행하세요: `adb shell appops set com.joyong.communitydetox.vr ACTIVATE_VPN allow`
5. (선택) VR 앱 차단 · 삭제 방지 · 퀘스트 브라우저 아예 막기는 접근성 권한이 필요합니다:
   ```
   adb shell settings put secure enabled_accessibility_services com.joyong.communitydetox.vr/com.joyong.communitydetox.DetoxAccessibilityService
   adb shell settings put secure accessibility_enabled 1
   adb shell dpm set-active-admin com.joyong.communitydetox.vr/com.joyong.communitydetox.DetoxAdminReceiver
   ```

**📖 모아읽기 (휴대폰·VR 앱에 합침)**: 예전 모아읽기 앱의 읽기 기능을 휴대폰 앱과 VR 앱 안에 넣었습니다. 펨코 해외축구·롤 인기글, 디시 특갤 개념글, 아카 나무 실검을 **이 앱 안에서만** 댓글까지 읽습니다. 브라우저에서는 이 앱의 VPN이 계속 막으므로 VPN 앱은 하나면 됩니다 (예전 모아읽기 앱은 지워도 됩니다).
- 페이지는 앱 안의 숨은 브라우저 화면이 열고, 글 내용은 안전한 태그만 남겨 다시 그립니다 (스크립트·외부 링크·외부 미디어 차단, 이미지는 앱을 거쳐 표시).
- 글/댓글 분석기는 모아읽기 1.2.4의 `sources.js` 를 그대로 사용합니다.
- 모아읽기는 항상 이 앱 안에서 읽을 수 있습니다 (VPN이 이 앱만 예외로 둠).

집중 디톡스, 일시정지, 직접 추가, 기록 등 나머지 기능은 휴대폰 버전과 같습니다.

## 설치하기

1. 이 저장소의 **Releases** 에서 `커뮤니티 디톡스 APK (최신 빌드)`의 `DigitalDetox.apk` 를 휴대폰으로 내려받습니다.
   (`community-detox/` 폴더가 바뀌어 푸시될 때마다 GitHub Actions가 자동으로 새로 빌드합니다. Actions 탭의 `Community Detox APK` 실행 결과에서도 받을 수 있습니다.)
2. 파일을 열어 설치합니다. "출처를 알 수 없는 앱" 설치를 허용해야 할 수 있습니다.
3. 앱을 열고 **접근성 설정 열기** → **커뮤니티 디톡스 차단** 을 켭니다.
4. Android 13 이상에서 **'제한된 설정'** 이라며 켜지지 않으면:
   앱의 **앱 정보 열기** → 오른쪽 위 **⋮** → **제한된 설정 허용** → 다시 접근성에서 켭니다.

## 개인정보

접근성 권한으로 확인하는 것은 **지금 앞에 열린 앱의 이름**과 **브라우저 주소창의 글자**뿐입니다.
이 정보는 차단 여부를 판단하는 데만 쓰이고, 저장하거나 외부로 보내지 않습니다.
인터넷 권한은 **네트워크 차단(VPN 방식)** 에서 차단하지 않는 주소의 DNS 조회를 원래 DNS 서버로 넘겨주는 데만 씁니다.

## 한계

- 인앱 브라우저는 앱이 화면 위쪽에 주소나 제목을 보여 줄 때만 알아볼 수 있어서, 앱 버전에 따라 일부는 막히지 않을 수 있습니다.
- 스스로를 돕는 도구입니다. 휴대폰 설정에서 접근성 권한을 끄거나 앱을 지우면 차단도 멈춥니다.

## 직접 빌드하기

Android Studio로 `community-detox` 폴더를 열거나, Android SDK가 있는 환경에서:

```bash
cd community-detox
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

- 최소 Android 8.0 (API 26), Java 17, Android Gradle Plugin 8.7
- 업데이트가 덮어 설치되려면 모든 빌드가 같은 키로 서명되어야 합니다. GitHub Actions는 처음 빌드할 때 서명 키를 만들어
  Actions 캐시에 보관하고 이후 빌드에서 계속 씁니다. (캐시는 7일 동안 빌드가 없으면 지워질 수 있습니다.)
  영구적으로 고정하려면 저장소 Secrets에 `DETOX_KEYSTORE_BASE64`, `DETOX_KEYSTORE_PASSWORD`, `DETOX_KEY_ALIAS`, `DETOX_KEY_PASSWORD` 를 넣으세요.

```
app/src/main/java/com/joyong/communitydetox/
├── Catalog.java                    # 기본 차단 목록 (커뮤니티 이름, 도메인, 앱 패키지)

├── DnsPacket.java                  # DNS 패킷 읽기/답 만들기
├── MainActivity.java               # 메인 화면 (차단 켜기, 집중 디톡스, 보호)
├── BlockListActivity.java          # 차단 목록 메뉴 (검색, 켜기/끄기, 직접 추가)
├── StoreSearch.java                # 스토어의 커뮤니티 앱 설치 화면 알아보기
├── ReaderActivity.java / ReaderBackend.java  # 모아읽기: 화면 + 숨은 페이지 불러오기
(app/src/main/assets/reader/)       # 모아읽기 화면 (index.html, reader.js, reader.css, sources.js)
├── BlockedActivity.java            # "디톡스 중이에요" 안내 화면
└── Ui.java                         # 코드로 만든 작은 UI 도구 (라이트/다크)
```
