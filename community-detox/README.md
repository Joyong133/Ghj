# 🌿 커뮤니티 디톡스 (Android)

커뮤니티 앱과 사이트를 막아 주는 안드로이드 앱입니다.
습관처럼 커뮤니티를 열면 화면을 닫고 "잠깐, 디톡스 중이에요" 안내와 함께 다른 할 일을 제안합니다.

## 무엇을 막나요?

| 구분 | 기본으로 막는 곳 |
| --- | --- |
| 국내 커뮤니티 | 디시인사이드, 에펨코리아, 더쿠, 루리웹, 클리앙, 뽐뿌, 인스티즈, 네이트판, 보배드림, 엠엘비파크, 오늘의유머, 82쿡, 웃긴대학, 인벤, 아카라이브, 개드립, 일간베스트, SLR클럽, 이토랜드, 와이고수, 다모앙, 퀘이사존 |
| 학교 · 직장 | 에브리타임, 블라인드 |
| 해외 · SNS | Reddit, X(트위터), 인스타그램, 페이스북, 스레드, 틱톡, 4chan, 9GAG |
| 기본 꺼짐 (켜서 사용) | 네이버 카페, 다음 카페, 디스코드, 유튜브 |

- 항목마다 켜고 끌 수 있고, **목록에 없는 사이트 주소**나 **설치된 앱**도 직접 추가할 수 있습니다.
- 사이트는 하위 주소까지 막습니다. (`dcinside.com` → `gall.dcinside.com`, `m.dcinside.com` 모두 차단)

## 기능

- **앱 차단**: 차단한 앱이 열리면 홈 화면으로 보내고 안내 화면을 띄웁니다.
- **사이트 차단**: 크롬, 삼성 인터넷, 웨일, 엣지, 파이어폭스, 오페라, 브레이브, 덕덕고 등 브라우저의 주소창을 확인해 차단한 사이트면 뒤로 돌아갑니다.
- **집중 디톡스 (잠금)**: 정한 시간 동안 차단을 끄거나 목록에서 뺄 수 없게 잠급니다. (추가는 언제든 가능)
  - 빠른 버튼(30분 ~ 7일) 또는 **일·시간·분을 직접** 고르거나 **끝나는 날짜·시각**을 지정할 수 있습니다.
  - 진행 중에는 +10분 ~ +3일 버튼이나 직접 정한 시간만큼 **연장**할 수 있습니다. (줄이기는 불가)
- **삭제 방지**: 앱 안에서 켜면 기기 관리자로 등록되어 바로 지울 수 없습니다. (지우려면 먼저 앱에서 삭제 방지를 끄세요)
  - 집중 디톡스 중에는 이 앱의 삭제 확인창, 설정의 앱 정보(강제 중지·데이터 삭제), 접근성 끄기, 삭제 방지 끄기 화면이 열리면 바로 닫습니다.
  - 그래서 집중 디톡스 중에는 설정 앱의 애플리케이션 목록이나 접근성 목록에서 이 앱이 화면에 보이면 홈으로 돌아갑니다.
  - 앱 업데이트 설치는 막지 않습니다. 안전 모드 부팅이나 PC(ADB)로 지우는 것까지는 막을 수 없습니다.
- **앱 업데이트**: 앱 맨 아래 "최신 버전 받기"로 새 APK를 받아 설치하면 설정과 기록을 그대로 둔 채 업데이트됩니다.
- **기록**: 오늘 참은 횟수, 누적 횟수, 디톡스 며칠째인지 보여 줍니다.
- 다크 모드 지원, 광고·추적·인터넷 권한 없음.

## 설치하기

1. 이 저장소의 **Releases** 에서 `커뮤니티 디톡스 APK (최신 빌드)`의 `CommunityDetox.apk` 를 휴대폰으로 내려받습니다.
   (`community-detox/` 폴더가 바뀌어 푸시될 때마다 GitHub Actions가 자동으로 새로 빌드합니다. Actions 탭의 `Community Detox APK` 실행 결과에서도 받을 수 있습니다.)
2. 파일을 열어 설치합니다. "출처를 알 수 없는 앱" 설치를 허용해야 할 수 있습니다.
3. 앱을 열고 **접근성 설정 열기** → **커뮤니티 디톡스 차단** 을 켭니다.
4. Android 13 이상에서 **'제한된 설정'** 이라며 켜지지 않으면:
   앱의 **앱 정보 열기** → 오른쪽 위 **⋮** → **제한된 설정 허용** → 다시 접근성에서 켭니다.

## 개인정보

접근성 권한으로 확인하는 것은 **지금 앞에 열린 앱의 이름**과 **브라우저 주소창의 글자**뿐입니다.
이 정보는 차단 여부를 판단하는 데만 쓰이고, 저장하거나 외부로 보내지 않습니다. 앱에는 인터넷 권한 자체가 없습니다.

## 한계

- 다른 앱 안에서 열리는 **내장 브라우저**(카카오톡 링크 등)는 막히지 않을 수 있습니다.
- 스스로를 돕는 도구입니다. 휴대폰 설정에서 접근성 권한을 끄거나 앱을 지우면 차단도 멈춥니다.

## 직접 빌드하기

Android Studio로 `community-detox` 폴더를 열거나, Android SDK가 있는 환경에서:

```bash
cd community-detox
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

- 최소 Android 8.0 (API 26), Java 17, Android Gradle Plugin 8.7
- 업데이트가 덮어 설치되려면 모든 빌드가 같은 키로 서명되어야 합니다. GitHub Actions는 처음 빌드할 때 서명 키를 만들어
  Actions 캐시에 보관하고 이후 빌드에서 계속 씁니다. (캐시는 7일 동안 빌드가 없으면 지워질 수 있습니다.)
  영구적으로 고정하려면 저장소 Secrets에 `DETOX_KEYSTORE_BASE64`, `DETOX_KEYSTORE_PASSWORD`, `DETOX_KEY_ALIAS`, `DETOX_KEY_PASSWORD` 를 넣으세요.

```
├── Catalog.java                    # 기본 차단 목록 (커뮤니티 이름, 도메인, 앱 패키지)

├── DetoxAccessibilityService.java  # 앞에 열린 앱/브라우저 주소를 보고 차단
├── MainActivity.java               # 설정 화면
├── BlockedActivity.java            # "디톡스 중이에요" 안내 화면
└── Ui.java                         # 코드로 만든 작은 UI 도구 (라이트/다크)
```
