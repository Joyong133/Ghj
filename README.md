# 코카콜라 이야기

코카콜라를 소개하는 한 페이지짜리 웹사이트입니다. 비공식 페이지입니다.

- **개요**: 어떤 음료인지, 이름의 유래(Coca + Kola), 원재료
- **역사**: 1886년부터 2005년까지의 주요 사건 연표
- **병**: 1915년 컨투어 병 디자인 이야기와 부분별 설명 그림
- **영양**: 제품과 용량을 고르면 열량·당류·카페인, 각설탕 개수, WHO 당류 권고량 대비 비율을 보여 주는 계산기
- **제품**: 코카콜라 패밀리와 코카콜라 컴퍼니의 다른 브랜드
- **Q&A**: 코카인, 비밀 레시피, 산타클로스 등 자주 궁금해하는 이야기

## 보는 방법

빌드 과정 없이 `index.html` 파일 하나로 되어 있습니다. 브라우저로 바로 열면 됩니다.
GitHub Pages에서 이 저장소의 루트를 배포해도 그대로 동작합니다.

영양 수치는 100ml당 근삿값(열량 43kcal, 당류 10.8g, 카페인 9.6mg)으로 계산합니다.
실제 값은 나라와 제품마다 다릅니다.

## 잠금화면 리더 (`lockscreen.html`)

txt 파일을 잠금화면 위에서 열어 읽는 한 페이지짜리 화면입니다. 브라우저로 바로 열면 됩니다.

- 왼쪽 아래 버튼으로 txt 파일을 고르거나 복사한 글을 붙여넣어 엽니다. 컴퓨터에서는 끌어다 놓기와 Ctrl+V도 됩니다.
- UTF-8과 EUC-KR(CP949) 인코딩을 자동으로 구분합니다.
- 읽던 위치와 보기 설정(글자 크기, 글꼴, 줄 간격, 바탕)은 이 브라우저에만 저장됩니다.
- 위젯의 눈 버튼으로 잠금화면에서 글 내용을 가릴 수 있습니다.
- 보기 설정의 '화면 켜두기'를 켜면 페이지가 열려 있는 동안 화면이 꺼지지 않습니다(지원하는 브라우저에서만).

### 휴대폰 홈 화면에 앱처럼 추가하기

GitHub Pages 등으로 배포한 주소에서 `lockscreen.html`을 연 뒤:

- **iPhone (Safari)**: 공유 버튼 → '홈 화면에 추가'
- **Android (Chrome)**: 오른쪽 위 메뉴 → '홈 화면에 추가' 또는 '앱 설치'

홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 열립니다(`lockscreen.webmanifest`, `lockscreen-icon-*.png`).
웹 페이지라서 휴대폰의 실제 시스템 잠금화면을 대신할 수는 없습니다.
