# 日本語ロック — 일본어 강제 학습 잠금화면 (v2.0)

**일본어 문제를 맞혀야만 잠금이 풀리는** 안드로이드 앱입니다.
화면을 켤 때마다 학습 잠금이 시스템 잠금화면 위에 먼저 나타납니다.
같은 학습 화면(`index.html`)은 브라우저에서 웹 버전으로도 쓸 수 있습니다.

## 📲 설치 (APK)

1. 휴대폰에서 [`dist/JapaneseLock-v2.0.apk`](dist/JapaneseLock-v2.0.apk) 를 내려받습니다 (GitHub에서 파일을 열고 **Download raw file**)
2. 설치할 때 "출처를 알 수 없는 앱 설치"를 허용합니다
3. 앱을 열고 **잠금 사용** 스위치를 켭니다
4. **다른 앱 위에 표시 → 허용하기**를 눌러 권한을 켭니다 (필수)
5. 삼성 등 일부 기기에서는 **배터리 최적화 제외**도 켜 주세요

- 지원: Android 8.0 (API 26) 이상
- 기존 PIN/패턴 잠금은 그대로 유지됩니다. 학습 잠금은 그 **위에** 한 겹 더 씌워지는 방식이라 기기 보안을 대신하지 않습니다.

## 🔒 강제력

| 장치 | 동작 |
|---|---|
| 화면 켤 때마다 잠금 | 포그라운드 서비스가 화면 꺼짐을 감지해서, 다음에 켤 때 학습 잠금을 먼저 띄웁니다 |
| 연속 정답 조건 | 설정한 횟수(기본 5회)를 **연속으로** 맞혀야 해제 |
| 오답 패널티 | 전부 초기화 / 2개 차감 / 1개 차감 / 없음 |
| 뒤로 가기 차단 | 잠금 화면에서 뒤로 가기가 막힙니다 |
| 탈출 방지 (강함) | 홈 버튼으로 빠져나가면 곧바로 다시 잠깁니다 |
| 사용 중 재잠금 | 해제하고 나서 5분~2시간 뒤에 다시 잠금 (선택) |
| 재부팅 후 자동 시작 | 휴대폰을 껐다 켜도 계속 작동합니다 |
| 전체화면 | 상태바와 내비게이션 바를 숨깁니다 |

### 🚨 안전장치
- **긴급 해제**: 버튼을 3/5/10초 동안 길게 누르면 문제를 풀지 않고 나갈 수 있습니다 (급한 전화 등). 사용 횟수는 통계에 남습니다.
- **통화 중에는 잠그지 않음**: 전화나 영상통화 중에는 잠금이 뜨지 않습니다.
- 앱에서 스위치를 끄면 언제든 완전히 해제됩니다.

## 📚 학습 콘텐츠 (8개 덱)

히라가나 46 · 가타카나 46 · 탁음/반탁음 25 · 요음 33 · N5 단어 66 · N5 한자 60 · 인사 표현 21 · 요일/의문사 19

**문제 유형**
- 가나 → 발음 고르기, 발음 → 가나 고르기 (역방향)
- 가나를 보고 로마자 **직접 입력** (찍기 불가 모드, `shi`/`si` 같은 표기도 모두 인정)
- 단어 → 뜻, 뜻 → 단어 (역방향)
- 한자 → 뜻, 한자 → 읽기

## ✨ v2 개선 사항

- **안드로이드 APK** (실제 잠금화면 동작, 재부팅 후 자동 시작)
- **간격 반복 학습**: 틀린 문제는 더 자주, 잘 아는 문제는 덜 자주 나옵니다
- **일본어 발음 듣기 (TTS)**: 답을 고르면 읽어 줍니다
- **오답 진동**
- 덱 8개 (v1은 4개), 역방향/입력형 문제, 보기 6개 모드
- 통계: 정답률, 연속 학습일, **최근 7일 그래프**, **자주 틀리는 항목 TOP 5**
- v1 웹 버전의 학습 기록은 자동으로 옮겨집니다

## 🛠 직접 빌드하기

```bash
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease
# → app/build/outputs/apk/release/
```

- 빌드할 때 저장소 루트의 `index.html`이 APK의 assets로 복사됩니다. 웹 버전과 앱이 같은 학습 화면을 씁니다.
- 릴리스 서명: `android/keystore.properties` 파일(storeFile, storePassword, keyAlias, keyPassword)이 있으면 그 키로 서명합니다. 키스토어는 git에 올리지 않습니다.

### 구조
```
index.html                     학습 UI (웹 + 앱 공용)
android/app/src/main/java/com/joyong/jlock/
  MainActivity.java            홈: 통계, 설정, 권한 안내, 잠금 켜기/끄기
  LockActivity.java            학습 잠금 화면 (잠금화면 위에 표시, 뒤로 가기 차단, 전체화면)
  LockService.java             포그라운드 서비스: 화면 꺼짐 감지, 재잠금 타이머, 통화 중 예외
  BootReceiver.java            재부팅 후 서비스 다시 시작
  Bridge.java                  JS ↔ 네이티브 브리지 (window.JLock)
  Speaker.java                 일본어 TTS
```
