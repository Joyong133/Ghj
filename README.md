# 코카콜라 이야기

코카콜라를 소개하는 한 페이지짜리 웹사이트입니다. 비공식 페이지입니다.

- **개요**: 어떤 음료인지, 이름의 유래(Coca + Kola), 원재료
- **역사**: 1886년부터 2005년까지의 주요 사건 연표
- **병**: 1915년 컨투어 병 디자인 이야기와 부분별 설명 그림
- **영양**: 제품과 용량을 고르면 열량·당류·카페인, 각설탕 개수, WHO 당류 권고량 대비 비율을 보여 주는 계산기
- **제품**: 코카콜라 패밀리와 코카콜라 컴퍼니의 다른 브랜드
- **Q&A**: 코카인, 비밀 레시피, 산타클로스 등 자주 궁금해하는 이야기

## 보는 방법

빌드 과정 없이 `index.html` 파일 하나로 되어 있습니다. 브라우저로 바로 열면 됩니다.
GitHub Pages에서 이 저장소의 루트를 배포해도 그대로 동작합니다.

영양 수치는 100ml당 근삿값(열량 43kcal, 당류 10.8g, 카페인 9.6mg)으로 계산합니다.
실제 값은 나라와 제품마다 다릅니다.

# 성벽 방어전 (`defense/`)

세븐나이츠의 방어전 모드(오토체스 방식)를 따라 만든 브라우저 게임입니다. `defense/index.html` 파일 하나로 되어 있어 브라우저로 바로 열면 됩니다.

- **소환**: 4골드로 무작위 영웅, 6골드로 고른 타입의 영웅(타입 소환)을 대기석에 소환
- **합성**: 같은 등급이면서 같은 타입인 영웅 둘 → 그 타입의 한 등급 위 무작위 영웅. ★5 둘을 합치면 30% 확률로 히든 영웅(레인저 제외), 최대 ★6. 일괄 합성·자동 배치 버튼 제공
- **배치**: 전열·후열 6칸 중 최대 5명. 근접 공격은 전열부터
- **수비대 레벨**: 골드로 올리면 영웅 능력치와 소환 고등급 확률 상승
- **시너지**: 공격형·마법형·방어형·지원형·레인저 수에 따라 아군 전체 강화 (지원형 3명이면 적 후열 스킬 무효화)
- **전투**: 자동 전투. AUTO를 끄면 게이지가 찬 영웅을 눌러 스킬을 직접 사용. 1x·2x·3x 속도, 전투 뒤 영웅별 피해·회복 기록
- **유물**: 3·5·10·15·20·25스테이지 뒤 세 개 중 하나 선택 (17종, 타입 문장 포함)
- **진행**: 5스테이지마다 보스, 30스테이지 마왕을 쓰러뜨리면 클리어(이후 무한 방어). 지면 남은 적 수만큼 성벽 피해
- **마스터리·도감**: 판이 끝나면 도달 스테이지만큼 명예를 받아 공격·생명·방어·군자금·성벽 마스터리를 올림. 만난 영웅은 도감에 기록

진행 중인 판, 명예·마스터리·도감, 설정은 브라우저 localStorage에 저장돼 새로고침해도 이어집니다.
