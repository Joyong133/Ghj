# 日本語ロック — 일본어 강제 학습 잠금화면

스마트폰 잠금화면처럼 작동하지만, **일본어 문제를 맞혀야만 잠금이 풀리는** 순수 웹앱입니다.
설치 없이 `index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.

## 핵심 아이디어 — "강제력"

단순 학습 앱과 달리, 다음 장치로 공부를 **강제**합니다.

| 강제 장치 | 설명 |
|---|---|
| 🔒 연속 정답 조건 | 설정한 횟수(기본 5회)를 **연속으로** 맞혀야 해제 |
| ⚠️ 오답 패널티 | 틀리면 연속 정답이 차감(전부 초기화 / 2개 / 1개 / 없음 중 선택) |
| ⏰ 자동 재잠금 | 해제 후 일정 시간(기본 5분)이 지나면 다시 잠김 |
| 🚪 탈출 방지 | 잠금 중 뒤로가기·우클릭·ESC 흡수, 닫기/새로고침 경고, 자리 이탈 시 재잠금 |
| 🖥️ 전체화면 모드 | 몰입도를 높여 강제력을 강화 |

> 참고: 웹 브라우저 보안 정책상 OS 수준의 완전한 잠금은 불가능합니다.
> 이 앱은 "닫기 전에 공부하게 만드는 학습 게이트" 로서 동작하며, 모든 방해 차단이 100% 보장되지는 않습니다.

## 학습 범위 (설정에서 선택)

- 히라가나 46자 (발음 맞히기)
- 가타카나 46자 (발음 맞히기)
- JLPT N5 기초 단어 (뜻 맞히기)
- 일상 인사 표현 (뜻 맞히기)

## 사용법

1. `index.html` 을 브라우저로 연다
2. 잠금화면을 위로 밀거나 눌러 학습 시작
3. 보기 중 올바른 발음/뜻을 선택
4. 목표 연속 정답 달성 시 해제 🎉
5. 우측 상단 ⚙️ 설정에서 난이도·강제력·학습 범위 조절

## 특징

- 100% 클라이언트 사이드 (서버·네트워크 불필요)
- 학습 통계(누적 정답, 연속 통과일, 오늘 해제 횟수)를 브라우저에 저장
- 데스크톱·모바일 모두 대응, 다크 테마
