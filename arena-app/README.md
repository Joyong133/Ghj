# Arena 윈도우 앱

[arena.ai](https://arena.ai)를 브라우저 없이 독립된 창으로 여는 윈도우 앱입니다.
안드로이드 앱과 같은 기능(저장한 프롬프트, 답변 분량, 스르륵, 고정 모드)이 들어 있습니다.

## 설치하기

- 설치형: **https://github.com/Joyong133/Ghj/releases/download/arena-windows-latest/Arena-Setup.exe**
  (바탕화면·시작 메뉴에 바로가기가 생깁니다)
- 설치 없이 실행: **https://github.com/Joyong133/Ghj/releases/download/arena-windows-latest/Arena-Portable.exe**

두 링크는 항상 최신 버전을 받습니다. 설치형은 새 버전을 받아 다시 설치하면 데이터(프롬프트, 설정)를
그대로 둔 채 업데이트됩니다.

코드 서명이 없는 앱이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜹니다. **추가 정보 → 실행**을 누르세요.

## 기능

화면 오른쪽에 버튼 세 개가 떠 있습니다. 위아래로 끌어서 옮길 수 있고, 옮긴 위치를 기억합니다.
창 위쪽의 메뉴(안 보이면 `Alt`)의 **도구**에서도 같은 기능을 쓸 수 있습니다.

| 버튼 | 단축키 | 기능 |
| --- | --- | --- |
| 🔖 노란 버튼 | `Ctrl+P` | **저장한 프롬프트**: 누르면 입력창에 바로 들어갑니다. 새로 만들기, 입력창 내용 저장, 수정·복사·맨 위로·삭제(⋮ 또는 오른쪽 클릭), 검색 |
| (프롬프트 목록 맨 위) | | **답변 분량 정하기**: 숫자 + 글자/문장/문단 + 이내/정도. 켜 두면 보낼 때 질문 끝에 분량 지시를 붙입니다 |
| ▶ 남색 버튼 | `Ctrl+J` | **스르륵**: 마지막 AI 답변을 처음부터 원하는 속도로 한 글자씩 다시 보여 줍니다. 서식은 그대로이고, 본 위치를 저장해서 다음에 이어서 봅니다 |
| 📌 버튼 | `Ctrl+L` | **고정 모드**: 배틀에서 공개된 AI(또는 다이렉트에서 쓰던 AI)로 고정해 다이렉트 모드에서 계속 대화합니다 |

스르륵 화면에서는 `스페이스`로 재생/일시정지, `+`/`-`로 글자 크기, `T`로 화면 색 바꾸기, `Esc`로 닫기입니다.
**끝까지 보기 잠금**(처음엔 켜짐): 스르륵을 켜면 다 볼 때까지 닫기(🔒)·`Esc`·`Ctrl+J`·다른 답변 고르기가 막히고,
새로고침하거나 앱을 다시 켜도 그 대화가 열리면 자동으로 이어서 보여 줍니다. 끝까지 보면 풀리고, 보기 설정에서 끌 수 있습니다.
**Aa 버튼(보기 설정)**에서 화면 색 8가지, 글자 크기, 줄 간격, 글꼴(고딕·명조), 글 폭, 읽는 줄 강조, 커서, 빗소리 크기를 바꿀 수 있고, 막대에 남은 시간이 나옵니다. 아래 막대에서 속도(초당 5~150자)를 바꿀 수 있습니다.
막대의 **비 내리기**를 체크하면 글 뒤로 비가 내리고(빗줄기·튀는 물방울·유리창 물방울·물안개), **빗소리**를 체크하면 빗소리도 납니다.

| 단축키 | 동작 |
| --- | --- |
| `Ctrl+H` | 홈으로 |
| `Alt+←` / `Alt+→` | 뒤로 / 앞으로 |
| `Ctrl+R` | 새로고침 |
| `Ctrl+=`, `Ctrl+-`, `Ctrl+0` | 확대, 축소, 원래 크기 |

데이터(프롬프트, 설정, 스르륵 위치)는 `%APPDATA%\Arena\arena-data.json`에 저장됩니다.

## 직접 빌드하기

Node.js 22 이상이 필요합니다.

```bash
cd arena-app
npm install
npm start            # 바로 실행
npm run dist:win     # 윈도우 설치 파일 → dist/
```

스르륵·고정·분량 스크립트는 안드로이드 앱과 같은 파일(`arena-android/app/src/main/assets/`)을 씁니다.
`npm start`와 빌드 명령이 실행 전에 `web/` 폴더로 복사합니다.

arena.ai는 외부 서비스이고, 이 앱은 그 웹사이트를 창에 띄워 주기만 하는 비공식 앱입니다.
