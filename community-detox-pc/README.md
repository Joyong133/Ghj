# 🌿 커뮤니티 디톡스 PC (Windows)

안드로이드 앱 [커뮤니티 디톡스](../community-detox/)의 Windows 10/11 버전입니다.
`CommunityDetox.exe` 파일 하나로 동작하고, 따로 설치할 것이 없습니다. (.NET Framework 4.8은 Windows에 기본으로 들어 있습니다)

## 받기

저장소 **Releases** 의 `커뮤니티 디톡스 PC (Windows) 최신 빌드` 에서 `CommunityDetox.exe` 를 받으세요.
`community-detox-pc/` 폴더가 바뀌면 GitHub Actions가 자동으로 새로 빌드합니다.

1. exe를 원하는 폴더(예: 문서)에 두고 실행합니다. (나중에 옮기면 다시 한 번 실행해 주세요)
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (코드 서명이 없는 프로그램이라 뜨는 안내)
3. 관리자 권한 요청에 **예** (hosts 파일을 바꿔 사이트를 막는 데 필요)

## 기능 (안드로이드 앱과 같음)

| 기능 | PC에서 동작 방식 |
| --- | --- |
| 커뮤니티 사이트 차단 | **hosts 파일**에 차단 주소를 넣어 모든 브라우저·프로그램에서 접속을 막고, 앞에 띄운 브라우저의 **창 제목·주소창**에 차단 사이트가 보이면 그 **탭을 닫습니다** (Ctrl+W). |
| 기본 차단 목록 | 디시인사이드, 에펨코리아, 더쿠, 루리웹, 클리앙, 뽐뿌, 인스티즈, 네이트판, 아카라이브, 에브리타임, 블라인드, Reddit, X, 인스타그램 등 (안드로이드와 같은 목록) |
| 직접 추가 | 사이트 주소, **프로그램**(예: `Discord.exe`, 실행 중인 프로그램에서 고르기) — 차단한 프로그램은 켜지면 바로 종료 |
| 카카오톡 인앱 브라우저 | 카카오톡 PC에서 링크를 눌러 카톡 안의 브라우저 창으로 열린 페이지가 차단 목록이면 그 창을 닫음. "아예 막기"를 켜면 카톡 안 링크 창을 모두 닫음 (대화방 창은 건드리지 않음) |
| 집중 디톡스 | 빠른 버튼(30분~7일), **일·시간·분 직접 입력**, **끝나는 날짜·시각 지정**, 진행 중 **연장**(+10분~+3일, 직접 입력) |
| 일시정지 (1회) | 집중 디톡스마다 한 번, 5·10·15·30분. 그동안 디톡스 시간은 멈춤 |
| 꺼지지 않게 보호 | 컴퓨터를 켜고 로그인하면 **바로 자동 시작**(작업 스케줄러, 관리자 권한 창 없이 · 노트북 배터리 상태에서도 · 며칠을 켜 둬도 계속), 시작되면 알림 표시. 사이트 차단(hosts)은 컴퓨터를 꺼도 남아 있어 켜자마자 적용, 창을 닫아도 트레이에서 계속 동작. 집중 디톡스 중에는 종료·제거 불가, 작업 관리자로 강제 종료해도 다시 켜짐(감시 프로세스 + 1분마다 확인), hosts 파일을 고쳐도 몇 초 안에 복구 |
| 기록 | 오늘 참은 횟수, 누적, 디톡스 며칠째 |

설정과 기록은 `C:\ProgramData\CommunityDetox\` 에 저장됩니다. 아무것도 외부로 보내지 않습니다.

## 업데이트

앱이 항상 켜져 있어도 됩니다. **보호 · 정보 → 업데이트 확인 / 지금 업데이트** 를 누르면
새 exe를 받아 파일을 바꿔 끼우고 바로 다시 켜집니다. 집중 디톡스 중에도 되고, 남은 시간·설정·기록은 그대로 이어집니다.
새 버전은 12시간마다 자동으로 확인해서 알림으로 알려 줍니다.

(동작 방식: 실행 중인 exe는 덮어쓸 수 없지만 이름은 바꿀 수 있어서, `CommunityDetox.exe` → `CommunityDetox.old.exe` 로 바꾸고
새 파일을 `CommunityDetox.exe` 자리에 넣은 뒤 새 버전을 실행합니다. 받은 파일이 커뮤니티 디톡스가 맞는지 확인한 뒤에만 실행합니다.)

## 제거

집중 디톡스가 끝난 뒤 앱의 **보호 · 정보 → 프로그램 제거** 를 누르고, `CommunityDetox.exe` 파일을 지우면 됩니다.

## 한계

- 스스로를 돕는 도구입니다. 안전 모드 부팅, 다른 관리자 계정, 시스템 시간 변경 같은 방법까지 막지는 않습니다.
- 브라우저가 이미 열어 둔 연결이나 VPN·프록시를 쓰면 hosts 차단이 늦거나 안 될 수 있지만, 그때도 창 제목·주소창 확인으로 탭을 닫습니다.
- 카카오톡 PC의 인앱 브라우저 창은 창 안의 웹 화면과 창 제목으로 알아봅니다. 카톡 버전에 따라 안 될 수 있습니다.

## 직접 빌드하기

.NET SDK 8 이상이 있으면 Windows, macOS, Linux 어디서나 빌드됩니다.

```bash
cd community-detox-pc
dotnet build -c Release
# 결과: bin/Release/CommunityDetox.exe
```

| 파일 | 내용 |
| --- | --- |
| `Catalog.cs` | 기본 차단 목록 (도메인, hosts용 하위 주소, 프로그램, 제목 키워드) |
| `Store.cs` | 설정·기록 저장, 집중 디톡스·일시정지, 주소/제목 판별 규칙 |
| `Blocker.cs` | hosts 파일, 브라우저 탭, 프로그램, 카카오톡 창 차단 |
| `Guard.cs` / `TaskXml.cs` | 자동 시작(작업 스케줄러), 감시 프로세스, 제거 |
| `Updater.cs` | 앱 안에서 업데이트 |
| `MainForm.cs` / `Dialogs.cs` / `Ui.cs` | 화면 |
