# Skyspire

구름 위에 떠 있는 100층짜리 성을 검 한 자루로 오르는 1인칭 검술 액션 RPG입니다.
브라우저에서 바로 실행되고, WebXR을 지원하는 VR 헤드셋(Meta Quest 브라우저 등)에서는 컨트롤러를 실제 검처럼 휘두르며 플레이할 수 있습니다.

"부유성의 층을 하나씩 공략한다"는 소드 아트 온라인풍 설정에서 출발했지만, 이름·캐릭터·로고·그림 같은 원작 요소는 쓰지 않았습니다. 게임 안의 지명, 몬스터, 검술 이름은 모두 새로 지었습니다.

## 실행하기

- **PC**: `index.html`을 브라우저로 엽니다. 빌드 과정이 없습니다. Three.js는 jsDelivr CDN에서 불러오므로 인터넷 연결이 필요합니다.
- **휴대폰**: 같은 파일을 열면 화면 버튼(이동 조이스틱, 공격, 검술, 회피, 방어)이 나타납니다.
- **VR**: WebXR은 HTTPS에서만 동작합니다. GitHub Pages 같은 HTTPS 주소에 올린 뒤 헤드셋 브라우저로 열고 타이틀의 **VR로 입장**을 누르세요.

진행 상황은 브라우저의 localStorage에 자동 저장됩니다. 다른 기기로 옮길 때는 설정 → 저장 코드 내보내기를 쓰고, 타이틀의 저장 코드 불러오기에 붙여 넣습니다.

## 게임 구성

- **100개 층, 10가지 테마**: 초원, 고목의 숲, 붉은 협곡, 설원, 독안개 늪, 황금 사구, 수정 공동, 잿빛 화산, 하늘 정원, 심연의 폐허. 층마다 지형, 마을, 길, 물(용암·독·얼음 포함), 몬스터 배치가 시드로 고정 생성됩니다.
- **층 공략 흐름**: 마을(안전 지대) → 필드 → 천장까지 솟은 미궁탑 → 미로 → 보스방. 보스를 쓰러뜨리면 다음 층이 열리고, 마을의 전이문으로 열린 층 사이를 오갈 수 있습니다. 위층의 바닥이 하늘을 덮고, 섬 아래로는 구름 바다가 보입니다.
- **몬스터 12종**: 멧돼지, 늑대, 슬라임(분열), 거대 말벌(급강하), 코볼트(방패), 골렘(내려찍기), 해골 검사(연속 베기), 리자드맨(옆걸음), 트렌트(뿌리 장판), 망령(순간이동), 갑각게(앞쪽 장갑, 돌진), 화염 임프(원거리). 공격 전에 빨갛게 빛나거나 바닥에 경고 표시가 뜹니다.
- **보스**: 층마다 이름과 종류가 다른 보스가 있고, 체력 단계마다 격노(충격파, 탄막, 부하 소환)합니다. 필드에는 5분마다 다시 나타나는 네임드 몬스터, 드물게 황금 몬스터가 나옵니다.
- **검술 10종**: 레벨에 따라 습득하고 쓸수록 숙련도(최대 10)가 올라 위력과 재사용 시간이 좋아집니다. 무기 종류(한손검, 세검, 곡도, 양손검, 단검)마다 쓸 수 있는 검술이 다릅니다.
- **성장**: 레벨과 능력치(STR·AGI·VIT), 5등급 장비(일반~전설), +10 강화, 층 재료로 희귀 무기 제작, 층마다 의뢰 3개, 도감과 업적 21개, 하드코어 모드(죽으면 저장 삭제).

### 플레이 시간

밸런스 공식(`src/01_data.js`의 `BAL`)으로 계산한 추정치입니다. 실제로 며칠씩 플레이해서 확인한 값은 아닙니다.

- 100층 돌파까지: 쉬지 않고 플레이하면 약 80~90시간(3~4일). 몬스터 한 마리에 20초, 층마다 마을·미궁·보스에 25분이 걸린다고 가정했습니다.
- 모든 검술 숙련도 10, 장비 +10, 전설 장비 수집, 의뢰 300개까지 하면 7일(168시간)을 넘습니다.

`BAL.expNext`의 지수(현재 1.072)를 바꾸면 전체 진행 속도가 바뀝니다.

## 개발

소스는 `src/` 아래에 나뉘어 있고, `node build.mjs`가 이를 이어 붙여 한 파일짜리 `index.html`을 만듭니다.

| 파일 | 내용 |
|---|---|
| `src/template.html` | HTML 구조와 CSS (HUD, 메뉴, 타이틀, 터치 버튼) |
| `src/00_core.js` | 유틸리티, 난수·노이즈, 저장소, 전역 상태와 입력 |
| `src/01_data.js` | 테마, 몬스터, 무기, 검술, 밸런스 공식, 퀘스트, 업적 |
| `src/02_audio.js` | Web Audio로 즉석 합성하는 효과음과 배경 음악 |
| `src/03_render.js` | 렌더러, 하늘·천장 셰이더, 입자·파편·검기·경고 표시 효과 |
| `src/04_world.js` | 층 지형, 풀, 나무, 마을, 미궁탑, 미로, 충돌 처리 |
| `src/05_entities.js` | 몬스터 모델과 AI, 보스 패턴, 투사체, NPC, 상자 |
| `src/06_player.js` | 이동, 1인칭 검 동작, 공격·검술, 회피·방어, VR 조작 |
| `src/07_ui.js` | HUD, 미니맵, 메뉴(화면용과 VR 패널용), 터치 조작 |
| `src/08_main.js` | 게임 흐름, 보상, 메뉴 내용, 저장, 입력, VR 세션, 메인 루프 |

```sh
cd skyspire
node build.mjs          # index.html 생성
```

주소 끝에 `?debug`를 붙이면 콘솔에서 `window.__sky`로 내부 상태를 볼 수 있습니다.

## 한계

- 그래픽은 외부 모델·텍스처 없이 코드로 만든 로우폴리 스타일입니다. 상용 VR 게임 수준의 사실적인 그래픽은 아닙니다.
- VR 조작은 WebXR 표준 컨트롤러 매핑을 기준으로 작성했고, 실제 헤드셋에서는 아직 시험하지 않았습니다.
- 멀티플레이는 없습니다.
