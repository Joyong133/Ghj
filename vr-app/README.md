# VR 검은 화면 (Android 앱)

실행하면 **화면 전체가 까맣게** 가려지고, 유튜브·음악 같은 **소리는 그대로** 나오는 앱입니다.
VR 고글에 끼워 소리만 들을 때, 주머니 속에서 화면이 눌리지 않게 할 때, 배터리를 아낄 때 쓸 수 있습니다.

## 설치

1. 이 저장소의 **Releases → `vr-app-latest`** 에서 `vr-black-screen.apk` 를 휴대폰으로 받습니다.
2. 파일을 열어 설치합니다. (처음이면 "출처를 알 수 없는 앱 설치"를 허용해야 할 수 있습니다.)
3. 앱을 열고 **"권한 허용하러 가기"** → "다른 앱 위에 표시"를 켭니다.

## 사용법

1. 유튜브에서 영상을 재생합니다.
2. 화면 위에서 알림창을 내리고 **"검은 화면"** 타일을 누릅니다.
   - 타일이 없으면 앱의 "빠른 설정에 타일 추가" 버튼(Android 13 이상)을 누르거나,
     알림창의 연필(편집) 아이콘에서 끌어다 놓습니다.
   - 타일 대신 앱의 **"10초 후에 켜기"** 를 누르고 10초 안에 유튜브를 열어도 됩니다.
3. 화면이 까맣게 되고 소리는 계속 나옵니다.
4. 끄려면 **검은 화면을 두 번 톡톡** 누르거나, 알림창의 **"끄기"** / 타일을 다시 누릅니다.

## 동작 원리

- "다른 앱 위에 표시" 권한으로 화면 전체를 덮는 검은 창을 띄웁니다. 아래에 있는 유튜브는
  화면에 보이는 상태로 남아 있어서 멈추지 않고, 소리는 건드리지 않습니다.
- 검은 창이 켜져 있는 동안 화면이 저절로 꺼지지 않게 하고, 밝기를 최저로 내립니다.
- 검은 창이 터치를 모두 받아서 아래 유튜브가 실수로 눌리지 않습니다. (볼륨 버튼은 그대로 됩니다.)
- 알림창 위쪽 상태 표시줄은 기기에 따라 보일 수 있습니다. Android가 앱이 그 부분을 덮는 것을 막기 때문입니다.

## 직접 빌드

```
cd vr-app
./gradlew assembleDebug
```

결과물: `app/build/outputs/apk/debug/app-debug.apk`. `vr-app/` 아래를 고쳐서 푸시하면
GitHub Actions(`.github/workflows/vr-app.yml`)가 APK를 다시 만들어 `vr-app-latest` 릴리스에 올립니다.
