# AI 규제 레이더 (Android 앱)

AI 규제 관련 뉴스를 한곳에 모아서, **규제가 셀수록 위험도가 올라가게** 보여 주는 안드로이드 앱입니다.
규제를 반기지 않는 입장 기준이라 금지·벌금·시행 같은 소식은 🔴 위험, 완화·유예·폐지 같은 소식은 🟢 평상시로 내려갑니다.

## 설치

1. 휴대폰에서 아래 링크를 누르면 최신 APK가 바로 받아집니다.
   https://github.com/Joyong133/Ghj/releases/download/ai-reg-radar-latest/AI-Regulation-Radar.apk
2. 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치합니다.
3. 새 버전도 같은 방법으로 받아 설치하면 기존 앱 위에 업데이트됩니다.

`ai-reg-radar/` 폴더가 바뀌어 푸시될 때마다 GitHub Actions가 APK를 새로 빌드해서 Release에 올립니다.

## 기능

- **뉴스 수집**: 구글 뉴스·빙 뉴스 RSS에서 한국어·영어 AI 규제 기사(최근 30일)를 모으고 중복을 없앱니다. API 키가 필요 없습니다.
- **한국어 번역**: 영어 기사 제목은 한국어로 번역해서 보여 주고, 원문 제목을 아래에 작게 같이 표시합니다. 번역은 한 번만 하고 저장해 둡니다(번역 실패 시 영어 그대로). 위험도 점수는 원문 기준으로 매깁니다.
- **기사별 위험도**: 기본 25점에서 시작해 제목·요약의 표현으로 점수를 더하고 뺍니다(0~100점).
  - 🔴 위험 75점 이상 — 금지, 벌금·과징금, 본격 시행, 법 통과, 제재·단속
  - 🟠 경고 55~74점 — 의무화, 규제 강화, 조사·소송
  - 🟡 주의 35~54점 — 법안 발의, 감독·인허가 논의
  - 🟢 평상시 35점 미만 — 일반 소식, 또는 규제 완화·유예·폐지·자율 규제·진흥
  - 기사마다 점수를 올린 표현(▲)과 내린 표현(▼)을 같이 보여 줍니다.
- **현재 위험도 게이지**: 최근 3일 기사 중 점수 상위 5건의 평균.
- **필터·정렬**: 등급별, 한국어/영어 기사, 최신순/위험도순.
- **지역 표시**: 🇰🇷 한국 · 🇪🇺 EU · 🇺🇸 미국 · 🇨🇳 중국 · 🇬🇧 영국 · 🇯🇵 일본.
- **위험 알림(선택)**: 메뉴에서 켜면 3시간마다 확인해서 새 🔴 위험 기사가 있을 때 알림을 보냅니다.
- 기사를 누르면 브라우저로 열리고, 길게 누르면 공유합니다. 마지막으로 받은 뉴스는 저장돼서 오프라인에서도 보입니다.

점수는 단어로 자동 판단하므로 실제 기사 내용과 다를 수 있습니다. 키워드와 가중치는
`app/src/main/java/com/ghj/aireg/RiskScorer.kt` 에서 고칠 수 있습니다.

## 직접 빌드

Android SDK와 JDK 17이 있으면:

```
cd ai-reg-radar
./gradlew assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```
