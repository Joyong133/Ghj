# 부산·울산 VR

부산과 울산을 실제 크기(1:1)로 걸어 다니고, 하늘을 날고, 지하철과 버스를 타 보는 WebXR 여행 앱입니다.
PC 브라우저, 휴대폰, VR 헤드셋(Meta Quest 브라우저 등)에서 실행됩니다.

도시를 손으로 만들지 않고, 실행하는 동안 공개 지도 데이터를 받아와 그 자리에서 세웁니다.

| 무엇 | 출처 |
|---|---|
| 건물 윤곽·높이, 도로, 다리, 철도, 버스 정류장과 노선, 역 | © OpenStreetMap 기여자 (Overpass API로 실시간 조회) |
| 땅에 입히는 위성 사진 | Esri World Imagery |
| 지형 고도(산, 언덕, 해안) | Mapzen Terrain Tiles (AWS Open Data) |

## 실행하기

- 인터넷 연결이 필요합니다. 처음 가는 곳은 건물을 불러오는 데 몇 초에서 수십 초가 걸리고, 한 번 불러온 곳은 브라우저에 저장돼 다음부터 빨리 뜹니다.
- **PC·휴대폰**: `index.html`을 브라우저로 엽니다. 빌드 과정은 없습니다.
- **VR**: WebXR은 HTTPS에서만 동작합니다. GitHub Pages 같은 HTTPS 주소에 올린 뒤 헤드셋 브라우저로 열고 **VR로 시작**을 누르세요.

## 할 수 있는 것

- **1:1 크기의 도시**: 위경도를 미터 단위 좌표로 바꿔 실제 거리 그대로 놓습니다. 높이 정보가 있는 건물은 그 높이로, 없는 건물은 종류(아파트, 상가, 사무실 등)로 높이를 추정합니다. 밤에는 창문에 불이 켜집니다.
- **걷기와 비행**: 걸을 때는 건물 벽과 바다에 막히고, 다리 위를 걸어서 건널 수 있습니다. 비행 모드로 바꾸면 시속 15~2,000km로 날 수 있고, 높이 올라갈수록 멀리까지 보입니다.
- **지하철·전철 6개 노선**: 부산 1~4호선, 부산김해경전철, 동해선. 역 이름 순서대로 OSM의 역 위치와 철길을 찾아 노선을 만들고, 열차가 정차와 출발을 되풀이하며 운행합니다. 역 가까이에서 `E`를 누르면 방향을 골라 탈 수 있습니다. 지하 구간에서는 터널이 보이고, 역마다 안내판(선택하면 음성 안내도)이 다음 역을 알려 줍니다.
- **버스**: 정류장 가까이에서 `E`를 누르면 그 정류장을 지나는 실제 노선(OSM에 등록된 노선)을 불러옵니다. 골라 타면 노선을 따라 정류장마다 서며 달립니다. 도로에는 승용차와 버스가 다닙니다.
- **공항**: 김해국제공항과 울산공항에서 비행기가 활주로 방향으로 착륙과 이륙을 되풀이합니다.
- **명소 72곳**: 해운대, 광안대교, 감천문화마을, 자갈치시장, 부산타워, 태종대, 해동용궁사, 태화강 국가정원, 대왕암공원, 간절곶 등 부산·울산 명소와 대학교(부산대, 부경대, 동아대, 한국해양대, UNIST, 울산대 등), 역과 공항, 터미널. 가까이 가면 안내 카드가 뜨고, 메뉴나 지도에서 골라 순간이동할 수 있습니다.
- **위성 지도**: `M`으로 지도를 열어 원하는 곳을 누르면 그 위치로 이동합니다.
- **시간대**: 실제 한국 시각을 따르거나 아침·낮·노을·밤으로 고정할 수 있습니다.

## 한계

- 건물은 OSM 윤곽을 세운 상자입니다. 지붕 모양, 외벽 재질, 실제 외관은 재현하지 않습니다. OSM에 없는 건물은 나오지 않습니다.
- 지하철은 실제 시간표가 아니라 노선 길이와 속도로 계산한 모의 운행입니다. 지하·고가 구간 구분은 OSM의 터널·다리 표시를 따릅니다.
- 버스는 OSM에 노선 관계(route=bus)가 등록된 정류장에서만 탈 수 있습니다.
- 비행기는 활주로 방향을 따라 움직이는 연출입니다.
- 명소 좌표는 대략값으로 넣어 두고, 주변 OSM 데이터에 같은 이름이 있으면 그 위치로 자동 보정합니다. 몇십 m 어긋날 수 있습니다.
- 지도 데이터 서버(Overpass)가 바쁘면 건물이 늦게 뜨거나 다른 서버로 다시 시도합니다.
- 개발 환경에서는 OSM 서버에 접속할 수 없어 실제 데이터 대신 가짜 데이터로 시험했습니다. 실제 데이터에서는 역 이름 맞추기나 버스 노선 잇기가 일부 실패할 수 있습니다.
- VR 조작은 WebXR 표준 컨트롤러 배치 기준으로 만들었고, 실제 헤드셋에서는 아직 시험하지 않았습니다.

## 개발

`src/` 아래 파일을 `node build.mjs`가 이어 붙여 한 파일짜리 `index.html`을 만듭니다.

| 파일 | 내용 |
|---|---|
| `src/template.html` | HTML 구조와 CSS |
| `src/00_core.js` | 좌표 변환(위경도 ↔ 미터), 타일 계산, IndexedDB 캐시, 입력 |
| `src/01_data.js` | 명소·대학교 목록, 지하철 노선과 역 이름, 공항 |
| `src/02_net.js` | Overpass 질의 큐(미러, 재시도, 캐시), 지형 고도·위성 사진 타일 |
| `src/03_render.js` | 렌더러, 하늘과 시간대, 바다, 건물 창문 재질, 이름표 |
| `src/04_terrain.js` | 가까운 타일(z15)과 먼 타일(z12) 지형, 나무 심기 |
| `src/05_city.js` | 건물 세우기, 도로·철길·다리, 정류장, 건물 충돌 |
| `src/06_transit.js` | 지하철 노선 만들기와 운행, 탑승, 버스 노선, 도로 차량, 비행기 |
| `src/07_player.js` | 걷기·비행, 탑승 시점, VR 컨트롤러 |
| `src/08_ui.js` | 안내판, 미니맵, 메뉴(화면·VR), 위성 지도, 터치, 명소 |
| `src/09_main.js` | 시작 화면, 메인 루프, 상호작용, 메뉴 내용, VR 세션 |

```sh
cd busan-ulsan-vr
node build.mjs
```

주소 끝에 `?debug`를 붙이면 콘솔에서 `window.__buvr`로 내부 상태를 볼 수 있습니다.
