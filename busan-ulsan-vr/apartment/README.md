# 빛이 머무는 쓰리룸 · VR 하우스 투어

부산·울산 VR(`../`)의 **해운대 아파트** 집 안입니다. 부산·울산 VR에서는 해운대 해수욕장 앞 45층 타워의 38층으로 들어가고, 이 폴더의 `index.html`을 열면 집만 따로(창밖은 꾸민 도시) 볼 수도 있습니다.

24층 남향 아파트의 쓰리룸 한 채를 브라우저와 VR 헤드셋으로 둘러보는 하우스 투어입니다.
PC 브라우저, 휴대폰, VR 헤드셋(Meta Quest 브라우저 등)에서 실행됩니다.

가상으로 꾸민 집입니다. 실제 분양 상품이나 단지와 관계없습니다.

## 집 구성

흔한 34평형(84㎡ 타입) 발코니 확장형 판상형 구조를 바탕으로 직접 설계했습니다. 아래 면적은 모형의 벽 중심선 기준으로 계산한 값입니다(합계 약 111㎡, 확장한 발코니 포함).

## 할 수 있는 것

- **걸어서 둘러보기**: 벽, 닫힌 문, 가구에 막히며 걷습니다. 현관은 한 단 낮습니다. 발소리가 바닥재(마루·타일)에 따라 다릅니다. `C`로 앉은 눈높이로 볼 수 있습니다.
- **조작**: 가운데 점을 맞추고 클릭하거나 `E`(터치는 누르기, VR은 트리거)
  - 문 8개(현관문·방문 등 여닫이, 부부욕실 미닫이, 유리 양개 중문)
  - 방마다 벽 스위치 9개(켜면 천장 등, 다운라이트, 간접조명이 함께 켜짐)
  - 커튼(속커튼 → 암막 → 모두 걷기 순서)
  - TV(움직이는 화면), 스탠드 에어컨, 스피커 음악, 아크 램프·협탁 스탠드, 컴퓨터 모니터
  - 냉장고 문(안쪽 조명), 주방·다용도실 수전, 인덕션, 샤워기, 욕조 물 받기
  - 로봇청소기(가구를 피해 거실을 돌아다님), 월패드
- **인테리어 스타일 4가지**: 모던 웜(헤링본 오크, 화이트 대리석), 스칸디 화이트(애쉬 마루, 원목 루버), 다크 럭셔리(월넛 헤링본, 네로 마르퀴나, 골드), 재패니(넓은 오크 마루, 석회 벽, 세이지 주방). 바닥, 벽, 아트월, 주방, 패브릭, 그림, 조명 색이 함께 바뀌고 테이블·의자 모양도 스타일에 맞게 바뀝니다.
- **시간대 4가지**: 아침(동쪽 낮은 해), 낮, 노을, 밤(단지 불빛과 별). 창으로 드는 햇빛 그림자가 바뀝니다.
- **조명**: 방별 켜고 끄기, 밝기, 색온도(전구색·주백색·주광색)
- **스마트홈 장면**: 귀가, 영화, 취침, 외출(로봇청소기 출발), 파티(간접조명 색이 바뀜), 아침
- **인형집 뷰**: 천장을 걷어 낸 집을 위에서 돌려 보고, 바닥을 누르면 그 자리로 내려갑니다. 방 이름과 면적이 표시됩니다.
- **가이드 투어**: 현관부터 창밖 풍경까지 11곳을 자막과 함께 차례로 보여 줍니다.
- **평면도**: 오른쪽 위 평면도에 내 위치와 시야, 문 열림, 가구가 보이고, 누르면 그 자리로 이동합니다.
- **줄자**: 벽·바닥·가구 위 두 점 사이 거리(가로·세로·높이)를 잽니다.
- **가구 옮기기**: 소파, 침대, 식탁, 의자, 화분 등을 들어 옮기고 돌릴 수 있습니다. `R`로 원래대로.
- **사진**: 보이는 장면을 PNG로 저장합니다.
- **소리**: 발소리, 문, 스위치, 커튼, 물, 에어컨, 로봇청소기, 음악을 모두 Web Audio로 합성합니다(소리 파일 없음).
- **창밖**: 24층 높이에서 보이는 아파트 단지, 강과 다리, 강 건너 빌딩, 먼 산

## 실행하기

- **PC·휴대폰**: `index.html`을 브라우저로 엽니다. 빌드 과정은 없습니다. three.js와 글꼴은 CDN에서 받으므로 인터넷 연결이 필요합니다.
- **VR**: WebXR은 HTTPS에서만 동작합니다. GitHub Pages 같은 HTTPS 주소에 올린 뒤 헤드셋 브라우저로 열고 **VR로 보기**를 누르세요.

## 한계

- 모든 재질과 가구는 코드로 만든 근사 모형입니다. 실시간 렌더링이라 빛이 벽에 튀는 간접광은 근사치로 흉내 냈고, 실내 조명은 그림자를 만들지 않습니다(햇빛만 그림자를 만듭니다).
- 창밖 도시는 상자 모양 건물로 꾸민 배경입니다.
- VR 조작은 WebXR 표준 컨트롤러 배치 기준으로 만들었고, 헤드셋을 흉내 낸 시험은 통과했지만 실제 헤드셋에서는 아직 시험하지 않았습니다. 인형집 뷰·가이드 투어·줄자·가구 옮기기는 PC·휴대폰에서만 됩니다.
- 실내 조명(점광원)이 열여섯 개라 성능이 낮은 기기에서는 느릴 수 있습니다.

## 개발

`src/` 아래 파일을 `node build.mjs`가 이어 붙여 한 파일짜리 `index.html`을 만듭니다.

| 파일 | 내용 |
|---|---|
| `src/template.html` | HTML 구조와 CSS (시작 화면, 방 정보, 평면도, 기능 막대, 패널) |
| `src/00_core.js` | three.js 불러오기, 도구 함수, 설정 저장, 입력, 짧은 애니메이션 |
| `src/01_plan.js` | 평면(방, 벽과 문·창, 조명 구역, 스위치 위치, 투어 지점) |
| `src/02_textures.js` | 마루·대리석·타일·패브릭·루버·러그·그림·잎·외벽 텍스처와 노멀맵 |
| `src/03_styles.js` | 인테리어 스타일 4가지와 공용 재질 |
| `src/04_render.js` | 렌더러, 하늘, 창밖 도시, 시간대 |
| `src/05_build.js` | 바닥·천장·벽·마감·창·문, 충돌, 조명 구역 |
| `src/06_furniture.js` | 가구 모형 |
| `src/07_interior.js` | 방마다 가구 배치와 조작(문, 스위치, 커튼, 가전, 로봇청소기) |
| `src/08_sound.js` | 합성 소리와 음악 |
| `src/09_player.js` | 충돌, 걷기, VR 컨트롤러·순간이동, 인형집 뷰, 가이드 투어 |
| `src/10_ui.js` | 화면 UI, 평면도, 패널, 스마트홈 장면, 줄자, 가구 옮기기, 사진, VR 손목 메뉴 |
| `src/11_main.js` | 시작 화면, 입력 연결, 스타일·시간 바꾸기, VR 세션, 메인 루프 |

```sh
cd busan-ulsan-vr/apartment
node build.mjs   # 혼자 열리는 index.html
cd .. && node build.mjs   # 부산·울산 VR에 넣어서
```

주소 끝에 `?debug`를 붙이면 콘솔에서 `window.__apt`로 내부 상태를 볼 수 있습니다.
