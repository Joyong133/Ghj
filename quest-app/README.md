# 퀘스트 검은 화면 (메타 퀘스트 앱)

메타 퀘스트에서 **시야 전체를 완전히 까맣게** 하고, 유튜브 **소리는 그대로** 들으면서
**유튜브 자막을 자동으로 가져와 눈앞 정중앙**에 띄우는 앱입니다.

## 설치

1. 이 저장소의 **Releases → `quest-app-latest`** 에서 `quest-black-screen.apk` 를 받습니다.
2. 퀘스트를 **개발자 모드**로 바꿉니다. (휴대폰의 Meta Horizon 앱 → 기기 → 헤드셋 설정 → 개발자 모드)
3. PC에서 **SideQuest** 또는 **Meta Quest Developer Hub**로 APK를 설치합니다.
4. 퀘스트 앱 목록에서 **"출처를 알 수 없음"** 으로 들어가 **퀘스트 검은 화면**을 실행합니다.

## 사용법

1. 유튜브 주소를 넣습니다. 퀘스트 브라우저에서 유튜브 영상을 열고 **공유 → 퀘스트 검은 화면**을 고르면 주소가 바로 들어갑니다.
2. 자막 크기와 "한국어 자막이 없으면 자동 번역"을 고르고 **검은 화면 시작**을 누릅니다.
3. 시야가 까맣게 되고, 소리가 나오며, 자막이 눈앞 2미터 정중앙에 나옵니다. 고개를 돌려도 정면에 따라옵니다.
4. 끄려면 컨트롤러 **트리거를 빠르게 두 번** 누르거나 **메타(∞) 버튼**을 누릅니다.

## 자막을 가져오는 방법

웹페이지에서는 유튜브가 자막을 못 가져가게 막지만, 이 앱은 앱 안에서 유튜브 페이지를 직접 엽니다.

- 앱 안의 보이지 않는 브라우저(WebView)가 PC용 유튜브 페이지로 영상을 재생합니다. 소리는 여기서 나옵니다.
- 영상마다 유튜브 플레이어의 자막을 켜고, 한국어 자막을 고릅니다. 한국어 자막이 없으면 유튜브의 자동 번역(한국어)을,
  그것도 끄면 원래 언어 자막을 씁니다.
- 0.15초마다 플레이어가 화면에 띄운 자막 글자를 읽습니다. 화면 자막을 못 읽으면, 플레이어가 받아 온 자막 파일을
  옆에서 함께 받아 두었다가 영상 시간에 맞춰 찾습니다.
- 읽은 글자를 그림으로 그려 OpenXR 쿼드 레이어로 눈앞 정중앙에 띄웁니다. 나머지 시야는 검은색입니다.

## 알아 둘 점

- 유튜브 페이지 구조가 바뀌면 자막 읽기가 안 될 수 있습니다. 그때는 `YouTubeScripts.java`의 자막 선택자를 고치면 됩니다.
- 광고가 나오면 광고가 끝난 뒤 자막이 나옵니다.
- 자막이 없는 영상은 "이 영상에는 자막이 없습니다"가 잠깐 나옵니다.

## 구조

| 파일 | 하는 일 |
| --- | --- |
| `LauncherActivity.java` | 처음 화면(주소·설정), 공유받기 |
| `VrActivity.java` | 몰입형 화면. WebView로 유튜브 재생, 0.15초마다 자막 읽기 |
| `YouTubeScripts.java` | 유튜브 페이지 안에서 실행하는 자막 켜기·읽기 스크립트, 주소 변환 |
| `CaptionImage.java` | 자막 글자를 가운데 정렬 그림으로 그리기 |
| `cpp/main.cpp` | OpenXR: 시야 전체 검은색 + 자막 쿼드 레이어 + 트리거 두 번 종료 |

## 직접 빌드

```
cd quest-app
./gradlew assembleDebug
```

`quest-app/` 아래를 고쳐서 푸시하면 GitHub Actions(`.github/workflows/quest-app.yml`)가 APK를 만들어
`quest-app-latest` 릴리스에 올립니다.
