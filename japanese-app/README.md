# 🦊 니홍고 마스터 — 듀오링고 스타일 일본어 학습 앱 (Android APK)

한국어 사용자를 위한 일본어 학습 앱입니다. 히라가나부터 JLPT N2까지 **15개 섹션**으로 되어 있고,
듀오링고처럼 경로를 따라 짧은 레슨을 풀며 실력을 쌓습니다. 전부 무료이고 광고가 없으며, 인터넷 없이도 동작합니다.

📦 **APK 다운로드:** [`dist/nihongo-master.apk`](dist/nihongo-master.apk)
(안드로이드 5.0 이상. 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.)

## 듀오링고보다 더 많은 기능

- **12가지 문제 유형**: 뜻 고르기, 그림 카드, 듣고 고르기, 짝 맞추기, 단어 타일로 번역 (일→한, 한→일),
  듣고 받아쓰기, 빈칸 채우기, 직접 입력 (로마자를 입력하면 가나로 자동 변환), 말하기 (음성 인식),
  가나·한자 따라 쓰기 (손가락으로 쓰면 채점), 문장 고르기
- **🔥 심화 레슨**: 유닛마다 보기 없이 직접 입력·받아쓰기·"보지 않고 쓰기"로 실력을 굳히는 레슨
- **한자 트랙 4단계**: 한국어 훈음으로 배우는 901자
- **문장 속 단어를 탭하면 뜻 표시**: 활용된 동사도 원형과 활용 이름을 알려 줍니다 (예: 食べました → 食べる · 정중 과거)
- **간격 반복(SRS) 복습**, 실수 노트, 문장 저장
- **무한 트레이너**:
  - 동사 활용 (20가지 형태: て형, 가능형, 수동, 사역, 사역수동…)
  - 형용사 활용
  - 숫자 (0 ~ 1억, 읽기·듣기)
  - 시각·날짜
  - 조수사 (本·匹·杯… 음편)
- **JLPT 모의고사** N5 / N4 / N3 / N2 (문자·어휘, 문법, 독해, 청해. 매번 새로 출제)
- **스피드 퀴즈** (가나 60초, 단어 90초), **플래시카드**
- **사전·도서관**: 통합 검색 (한국어·일본어·로마자), 가나표, 한자 사전, 단어장, 문법 가이드, 표현집,
  활용표, 숫자·날짜 읽기표
- **게임 요소**: XP, 연속 학습(스트릭), 일일 목표, 하트, 보석, 상점 (스트릭 프리즈, XP 2배 부스트),
  리그 10단계 (브론즈 → 다이아몬드), 일일 퀘스트, 업적 17종 (레벨별), 학습 달력, 통계
- **설정**: 후리가나와 로마자 표시, 무제한 하트, 모든 유닛 잠금 해제, 다크 모드, 음성 속도, 학습 기록 백업·복원

## 음성 (TTS)과 음성 인식

- 발음은 안드로이드에 설치된 **일본어 TTS**로 재생합니다. 기본 엔진(예: 삼성 TTS)이 일본어를 지원하지 않으면
  Google TTS로 자동 전환합니다. 소리가 나지 않으면 앱의 **프로필 → 설정 → 일본어 음성 설치**에서
  Google 음성 데이터(일본어)를 내려받으세요.
- 말하기 문제는 기기의 음성 인식(Google 앱)을 사용합니다. 쓸 수 없으면 "지금은 말할 수 없어요"를 눌러 건너뛰면 됩니다.

## 직접 빌드하기

Gradle이나 Android Studio 없이 Ubuntu/Debian 패키지만으로 빌드합니다.

```bash
sudo apt-get install -y aapt zipalign apksigner dalvik-exchange openjdk-17-jdk python3-pil nodejs
cd japanese-app
./build.sh          # → dist/nihongo-master.apk
```

`android.jar`(API 34)은 처음 빌드할 때 자동으로 내려받습니다.
빌드할 때 `tools/check-data.js`가 데이터 형식을 검사합니다.

브라우저로 보려면 `web/index.html`을 열면 됩니다. 이 경우 음성은 브라우저의 Web Speech API를 씁니다.

### 콘텐츠 추가

`web/data/units_s*.js`에 유닛을 추가하면 레슨이 자동으로 생성됩니다.

```js
UNITS.push({ id: 'myunit', sec: 3, t: '유닛 이름', e: '🎯',
  tip: { t: '문법 제목', b: '<p>해설 HTML</p>', ex: ['例文[れいぶん]です。|예문입니다.'] },
  w: `食べる|たべる|먹다|v1|🍽️`,               // 표기|읽기|뜻|품사|이모지
  s: `私[わたし] は パン を 食[た]べます。|저는 빵을 먹어요.`  // 띄어쓰기 = 타일 경계, 漢字[かな] = 후리가나
});
```

품사 코드: `n` 명사, `v5` 5단 동사, `v1` 1단 동사, `vs` する동사, `vk` 来る, `ai` い형용사, `an` な형용사,
`adv` 부사, `exp` 표현 등. 동사·형용사는 품사를 정확히 적으면 활용 트레이너와 탭 힌트에 자동으로 반영됩니다.

## 서명 키 안내

`build.sh`는 `keystore/nihongo-release.jks`가 없으면 서명 키를 새로 만듭니다. 이 키는 비밀 정보라서
저장소에 커밋하지 않습니다(`.gitignore` 처리).
안드로이드는 같은 키로 서명된 APK만 기존 앱 위에 업데이트로 설치할 수 있습니다. 앞으로 직접 빌드해서
업데이트하려면 이 키 파일을 안전한 곳에 따로 보관하세요. 경로와 비밀번호는 `KEYSTORE`·`KS_PASS` 환경 변수로
바꿀 수 있습니다. 다른 키로 서명된 APK를 설치하려면 기존 앱을 먼저 지워야 합니다.
