# AI 대체 확률 (안드로이드 앱)

한국·일본 개발자가 AI로 대체될 확률을 **실시간 뉴스 + AI 성능 가정**으로 추정해 보여 주는 앱입니다.

📦 설치 파일: [`release/AI-Replace-Meter-1.0.apk`](release/AI-Replace-Meter-1.0.apk) (Android 8.0 이상)
휴대폰에서 받은 뒤 "출처를 알 수 없는 앱 설치"를 허용하고 설치하세요.

## 화면 구성

- **🇰🇷 한국 / 🇯🇵 일본 게이지** — 두 나라 확률을 나란히 비교. 카드를 누르면 아래 상세가 바뀝니다.
- **조건 설정** — 직군(프론트엔드, 백엔드, QA, SI 등 10개), 경력(신입/중급/시니어), 기간(3/5/10년),
  AI 코딩 성능 가정치(30~100%, SWE-bench Verified 류 해결률) 슬라이더
- **요인 분석** — 각 요인이 확률을 얼마나 올리고(빨강) 내리는지(초록) 막대로 표시
- **확률 추이** — 새로고침할 때마다 기록된 뉴스 지수로 두 나라 추이를 그래프로 표시
- **실시간 뉴스** — 분석에 쓴 기사 목록과 기사별 위험/완화 판정. 누르면 원문이 열립니다.

## 계산 방식

`확률 = sigmoid(기본값 + Σ 가중치 × (요인 − 0.5))` 형태의 로지스틱 모형입니다.

| 요인 | 한국 | 일본 | 방향 |
|---|---|---|---|
| AI 코딩 성능 (가정치 + 글로벌 AI 뉴스 모멘텀 ±6%p) | 공통 | 공통 | ↑ |
| AI 도입 속도 | 64% | 46% | ↑ |
| 직무 노출도 (직군별) | 공통 | 공통 | ↑ |
| 실시간 뉴스 지수 (−1~+1) | 한국어 기사 | 일본어 기사 | ↑ |
| 인력 부족도 | 38% | 82% | ↓ |
| 고용 보호 | 52% | 74% | ↓ |
| 경력 / 기간 | 선택값 | 선택값 | 신입·장기일수록 ↑ |

- **실시간 뉴스**: Google 뉴스 RSS에서 최근 14일 기사(한국어·일본어·영어 각 최대 25건)를 받아
  헤드라인의 위험 키워드(대체·감원·채용 급감 / 代替·人員削減 …)와 완화 키워드(인력난·몸값 상승 / 人材不足·採用拡大 …)를
  세고, "대체 불가" 같은 부정 표현은 완화로 처리합니다. 최근 기사일수록 가중치가 큽니다(반감 약 5일).
- 앱을 켜면 30분이 지났을 때 자동으로 새로고침하고, 오프라인이면 마지막으로 받은 값을 씁니다.
- 기본 조건(전체 평균·중급·5년·AI 성능 80%·뉴스 중립)에서 한국 약 44%, 일본 약 22%가 나옵니다.

> 국가별 값과 가중치는 공개 통계의 경향을 반영한 **가정**입니다. 재미·참고용 지표이며 실제 미래를 예측하지 않습니다.

## 빌드

```bash
cd ai-replace-meter
./gradlew testDebugUnitTest assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

Android SDK(platform 34, build-tools 34)가 필요합니다. `ai-replace-meter/` 아래를 바꿔 푸시하면
GitHub Actions(`.github/workflows/ai-replace-meter-apk.yml`)가 APK를 빌드해 아티팩트로 올립니다.
release 빌드는 사이드로딩용으로 디버그 키로 서명되어 있습니다.
